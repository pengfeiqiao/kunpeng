# 即梦 Seedance 影视级地理特效提示词

使用说明：将以下提示词手动输入即梦 Seedance 2.0，生成影视级地理视频。

---

## 通用基础提示词模板

### 高冷史诗风格（epic-cold）

**适用场景：** 高山、高原、冰川、史诗感强的地理主题

**视觉特征：**
- 深蓝色调、低饱和度（< 0.35）
- 精细等高线、科学标注
- 极慢镜头、信息密集

**即梦提示词：**

```
影视级地理纪录片风格，新山海经《地球战损美学》参考。

视觉风格：深蓝色调、低饱和度、冷色调氛围。
构图：电影级宽画幅（16:9），史诗感。
镜头运动：极慢速推拉镜头（0.5x-1x），稳定航拍。
光影：自然光，高对比度，冷色调，黎明或黄昏光线。
细节：精细等高线纹理、海拔数据可视化、专业地图风格。

色彩系统：
- 主色调：深蓝、灰蓝、灰白
- 标注色：白色、黄色（少量使用）
- 饱和度：低（< 0.35）

特效元素：
- 云雾缭绕效果
- 地形等高线叠加动画
- 海拔数据标注动画（淡入淡出）
- 比例尺和指南针图形

转场效果：淡入淡出、横扫、缩放。

音频建议：史诗感配乐，自然环境音（风声、火山轰鸣）。
```

## 即梦生成参数建议

### 视频参数

```
分辨率：4K (3840x2160) 或 2K (2752x1536)
帧率：30fps
时长：3-5秒/场景
比例：16:9（横屏）
```

### 质量设置

```
画质：最高
风格强度：中等（平衡真实感与艺术性）
运动平滑度：高
细节增强：中等
```

### 特效参数

```
光影效果：开启
粒子效果：开启（适场景）
动态模糊：低（保持清晰）
色彩校正：自动
```

## 使用建议

1. **先选择风格**：根据场景选择高冷史诗/生机活力/季节人文/混合风格
2. **填写场景描述**：在"场景要求"中填写具体的地理场景
3. **调整参数**：根据需要调整分辨率、时长等参数
4. **测试生成**：先生成一段测试效果
5. **批量生成**：测试通过后批量生成分镜

---

**注意事项：**
- 所有提示词已移除文字标注要求
- 避免出现无关地点的文字（如"吉林"、"香格里拉"等）
- 专注于当前场景的地理特征和视觉呈现
- 首次生成建议使用中等参数，测试通过后再提升质量

# 地理视频风格参考

本文件包含地理视频的完整风格分析和提示词模板，用于指导 AI 生图系统生成符合要求的图片。

---

## 风格决策树

```
输入：地理文案
    │
    ├─> 地理类型？
    │   ├─> 高山/高原 → epic-cold
    │   ├─> 河流/海洋 → vitality
    │   ├─> 城市/人文 → seasonal-hybrid
    │   └─> 复杂/混合 → mixed
    │
    ├─> 情感需求？
    │   ├─> 史诗感/震撼 → epic-cold
    │   ├─> 活力/动感 → vitality
    │   ├─> 温暖/亲切 → seasonal-hybrid
    │   └─> 平衡/综合 → mixed
    │
    └─> 季节因素？
        ├─> 冬季/寒冷 → epic-cold
        ├─> 春夏 → vitality
        ├─> 秋季 → seasonal-hybrid
        └─> 不明显 → 混合类型决定
```

## 风格详解

### 1. 高冷史诗风格 (epic-cold)

**参考案例：** 《地球战损美学！香格里拉的真相》【新山海经】

**色彩系统：**
- 主色调：深蓝、灰蓝、灰白
- 饱和度：低（< 0.35）
- 亮度：中等偏低
- 对比度：中等（~45）

**场景类型：**
- 地图/地形类（52%）：等高线、地名标注、3D 地形
- 氛围场景类（8%）：开场氛围、转场

**标注元素：**
- 地名标注（中文 + 拼音）
- 等高线（精细、多层次）
- 海拔数据（白色/黄色文字）
- 路径指示（虚线/箭头）
- 比例尺和指南针

**镜头节奏：**
- 极慢镜头（0.5x - 1x）
- 史诗感，信息密集

**适用场景：**
- 高山、高原、冰川
- 史诗感强的地理主题
- 科学严谨的地理讲解
- 寒冷地区、冬季场景

**核心提示词元素：**
```
地理科普视频风格，高冷史诗美学
视觉特征：深蓝色调、低饱和度、精细等高线、科学标注、极慢镜头感
核心元素：
- 地形等高线（精细、多层次）
- 高海拔数据标注（白色/黄色文字）
- 地名标注（中文+拼音）
- 比例尺和指南针
- 冷色调氛围（深蓝、灰蓝、灰白）
构图：电影级宽画幅，史诗感
光影：自然光，高对比度，冷色调
细节：高保真地理数据可视化，专业地图风格
```

### 2. 生机活力风格 (vitality)

**参考案例：** 《中国第二大河：区区千重山，闯闯又能怎？》【新山海经】

**色彩系统：**
- 主色调：冷暖对比（蓝绿 + 橙黄）
- 饱和度：中等（0.385）
- 亮度：中等
- 对比度：中等（~50）

**场景类型：**
- 复杂场景+地图+标注（35%）：实景+地形标注+数据
- 复杂场景（22%）：航拍、实景、河流景观
- 地图/地形+标注（17%）：纯地图、地形标注

**标注元素：**
- 实景航拍 + 地形标注叠加
- 动态箭头指示河流流向
- 城市和人文地标标注
- 数据可视化元素（流速、流量等）

**镜头节奏：**
- 中等镜头（0.8x - 1.5x）
- 流动感，活力

**适用场景：**
- 河流、湖泊、海洋
- 动感强的地理主题
- 包含人文元素的地理讲解
- 春夏场景、温暖地区

**核心提示词元素：**
```
地理科普视频风格，生机活力美学
视觉特征：冷暖对比、中等饱和度、动态箭头、人文元素、流动感
核心元素：
- 实景航拍 + 地形标注叠加
- 动态箭头指示河流流向
- 城市和人文地标标注
- 冷暖色调对比（蓝绿+橙黄）
- 数据可视化元素
构图：广角镜头，活力感
光影：温暖阳光，中等对比度
细节：流动感，人文气息，数据可视化
```

### 3. 季节人文风格 (seasonal-hybrid)

**参考案例：** 《据说东北最低调的省份，是吉林？》【4K】

**色彩系统：**
- 主色调：冷暖对比强烈
- 饱和度：中等（0.353）
- 亮度：最高（129.6）
- 对比度：最高（59.6）

**场景类型：**
- 复杂场景+标注（约 65%）：实景+季节标注+文化元素

**标注元素：**
- 季节标注（春/夏/秋/冬图标或文字）
- 省份边界和行政区域
- 城市/景区标注
- 文化元素符号（如吉林的雾凇、长白山天池）

**镜头节奏：**
- 中等镜头（1x - 1.5x）
- 明亮通透，层次分明

**适用场景：**
- 城市、省份、地区介绍
- 季节性地理主题
- 包含强烈人文元素的地理讲解
- 秋季场景、强对比主题

**核心提示词元素：**
```
地理科普视频风格，季节人文美学
视觉特征：冷暖对比强烈、高对比度、明亮、季节元素、人文情怀
核心元素：
- 季节标注（春/夏/秋/冬）
- 省份边界和行政区域
- 城市/景区标注
- 文化元素符号
- 强烈的色彩对比
构图：明亮通透，层次分明
光影：高亮度，强对比
细节：季节感，人文元素，视觉冲击力
```

---

### 4. 混合风格 (mixed)

**特点：** 综合多种风格元素，适用于复杂、多层次的地理主题

**视觉特征：**
- 冷色调主导
- 信息密集
- 多种标注系统
- 动态节奏

**核心提示词元素：**
```
地理科普视频风格，混合美学
综合风格特征：冷色调主导、信息密集、多种标注系统、动态节奏
核心元素：
- 地图/地形层（等高线、海拔数据）
- 实景场景层（航拍、风景）
- 标注层（地名、数据、路径）
- 色彩层（冷色调主导，暖色点缀）
- 转场元素（箭头、边界线）
构图：信息密集但不混乱，层次分明
光影：自然真实，专业地图感
细节：多元素融合，信息可视化，专业地理风格
```

## 通用提示词结构

无论选择哪种风格，完整的提示词都应该包含以下部分：

### 1. 风格定义（必选）
```
地理科普视频风格，[风格名称]美学
视觉特征：[视觉特征描述]
```

### 2. 核心元素（必选）
```
核心元素：
- [元素1]
- [元素2]
- [元素3]
...
```

### 3. 场景要求（必选）
```
场景要求：[用户输入的场景描述]
```

### 4. 构图、光影、细节（可选但推荐）
```
构图：[构图风格]
光影：[光影效果]
细节：[细节要求]
```

## API 配置建议

### BananaPro nano-banana-2

**Base URL:** `https://www.dmxapi.cn`

**生图端点:** `/v1/images/generations`

**推荐配置（地理视频）：**
- **宽高比:** 16:9（横屏，适合地图和地形展示）
  - 4K: 5504x3072（推荐，质量最好）
  - 2K: 2752x1536（中等）
  - 1K: 1376x768（快速预览）

- **数量:** 1（BananaPro 只支持单张生成）

- **返回格式:** url（返回图片链接）或 b64_json（Base64 编码）

## 质量检查清单

生成的图片应该满足：

- [x] 符合选择的风格特征（色彩、饱和度、对比度）
- [x] 包含地理标注元素（地名、数据、等高线等）
- [x] 信息密集但不混乱
- [x] 适合视频分镜使用（构图、节奏）

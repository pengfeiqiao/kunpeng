### 阶段2：豆包分析优化

#### lights_rear 优化历程

**问题1**：尾灯点亮状态错误，使用了旧款设计

**豆包分析（第1次）**：
- 问题：尾灯轮廓完全不符，内部结构错误，车身曲面不符
- 原因：提示词过于模糊，"1:1复刻"没有明确维度
- 优化：中英文混合，明确尾灯未点亮状态

**豆包分析（第2次）**：
- 问题：还是有旧款设计混入
- 原因：中文泛化性描述对Gemini约束力弱
- 优化：使用英文强约束 + 中文具体要求

**豆包分析（第3次）**：
- 问题：极简正向指令还是失败
- 原因："1:1复刻"太模糊，AI无法准确理解
- **最终优化**：
  - 英文开头强约束
  - 明确尾灯未点亮状态
  - 拆分特征维度
  - 使用正向指令而非否定式

**结果**：✅ 第4次生成成功

**关键教训**：
- 提示词需要中英文混合
- 必须明确状态（点亮/未点亮）
- 拆分维度比模糊的"1:1复刻"更有效
- 正向指令 > 否定式指令

#### body_rear 优化历程

**问题1**：生成了5张拼接图而非单张完整图

**豆包分析**：
- 问题：多图拼接，尾灯错误，缺少"华晨宝马"标识，logo是旧款
- 原因：提示词没有明确禁止多图拼接和画面补全
- 优化：明确要求单张图像，禁止多图拼接

**问题2**：尾灯是旧款，缺少"华晨宝马"标识

**豆包分析（第2次）**：
- 问题：缺少中文标识，额外添加了"XDrive 30L"
- 原因：提示词没有明确要求保留具体标识
- **最终优化**：
  - 明确要求保留"华晨宝马"标识
  - 明确禁止添加额外标识
  - 强调尾灯使用新款设计
  - 强调logo使用新款样式

**结果**：✅ 第3次生成成功

**关键教训**：
- 必须明确禁止多图拼接
- 必须明确要求保留哪些具体标识
- 必须禁止添加参考图不存在的元素
- 使用"禁止调用旧款通用训练数据"约束

## 提示词演进

### V1 - 详细描述版本（失败）
```
生成宝马X3的尾灯，包含3条红色灯条，上下各一条，中间一条白色灯带...
```
**失败原因**：违反V3极简策略，AI随意发挥

### V2 - 模糊的极简版本（失败）
```
# 最高优先级
完全1:1复刻参考图
```
**失败原因**：太模糊，AI调用了旧款X3训练数据

### V3 - 平衡版本（部分成功）
```
# Top Priority
参考图是唯一设计来源
DO NOT use any design outside reference images
```
**失败原因**：否定式指令效果弱，没有明确维度

### V4 - 中英文混合版本（成功）
```
# HIGHEST PRIORITY (ENFORCE STRICTLY)
The provided reference image is the ONLY source...

# 核心复刻要求（必须100%执行）
完全匹配参考图的所有几何特征：包括尾灯的整体轮廓、尾灯内部所有结构...
尾灯保持参考图的未点亮状态，不添加任何发光效果。
```
**成功原因**：
1. 英文强约束 + 中文具体要求
2. 明确尾灯状态（未点亮）
3. 拆分维度（轮廓、结构、曲面、位置）
4. 正向指令为主

## 技术要点

### 1. 参考图选择
- 需要23张高质量参考图
- 包含多角度（前、后、侧、45度）
- 包含细节特写（轮毂、logo、灯组、传感器）
- 避免模糊、逆光、过度PS的图片

### 2. 豆包分析的关键作用
- **自动检测问题**：构图、设计、细节、风格
- **根本原因分析**：不只是表面问题，深入分析提示词缺陷
- **优化提示词**：针对具体问题优化，不是泛泛的"优化"
- **迭代验证**：每次优化后重新检查，直到成功

### 3. 人工干预时机
- 连续2次生成失败
- 豆包分析发现严重问题
- 细节错误（标识、logo等）
- 构图完全错误（多图拼接）

### 4. 质量检查标准
- ✅ 单张完整图像（非拼接）
- ✅ 主要设计元素正确
- ✅ 细节准确（标识、文字、logo）
- ✅ 风格一致（新旧款不混淆）

## 最佳实践总结

### ✅ 成功的做法

1. **提示词设计**
   - 中英文混合（英文强约束 + 中文具体要求）
   - 明确状态（点亮/未点亮、新款/旧款）
   - 拆分维度（轮廓、结构、曲面、位置）
   - 正向指令为主，否定式为辅

2. **质量保证**
   - 使用豆包进行质量检查
   - 使用豆包进行深度分析
   - 根据分析结果针对性优化
   - 迭代验证直到成功

3. **参考图选择**
   - 多角度覆盖
   - 细节特写充足
   - 质量高、清晰度好

4. **人工干预**
   - 及时介入（2次失败后）
   - 深入分析（不只是看表面）
   - 针对性优化（不是泛泛优化）

### ❌ 失败的做法

1. **提示词错误**
   - 详细描述具体特征（违反V3极简策略）
   - 模糊的"1:1复刻"（AI无法理解）
   - 纯否定式指令（效果弱）
   - 纯英文或纯中文（效果都不理想）

2. **质量保证错误**
   - 不使用AI分析
   - 只看表面问题
   - 泛泛优化而非针对性优化
   - 不迭代验证

3. **人工干预错误**
   - 介入太晚（浪费多次生成）
   - 只看表面不深入分析
   - 盲目优化而非针对性优化

## 通用化建议

### 对于其他车型的建议

1. **提示词模板**
   - 使用通用模板 + 参数化（{brand}, {model}）
   - 不要硬编码具体特征
   - 保持V3极简策略

2. **质量检查**
   - 必须使用豆包AI分析
   - 重点关注：构图、设计、细节、风格
   - 根据分析结果针对性优化

3. **迭代策略**
   - 最多重试5次
   - 每次重试前必须分析失败原因
   - 如果5次都失败，考虑参考图质量问题

4. **成本控制**
   - 预估成本：$1-2 per车型
   - 预估时间：2-4小时 per车型
   - 失败重试会增加成本和时间

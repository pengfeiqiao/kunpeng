# 汽车模型生成技能 V3

专业的汽车3D模型图片生成技能，使用Gemini API生成高质量汽车展示图片，并通过豆包AI进行质量分析和优化。

## 核心能力

- **多参考图融合**：支持最多6张参考图融合生成
- **智能提示词系统**：通用化提示词，适配任意车型
- **AI质量分析**：集成豆包视觉分析，自动检测生成问题
- **迭代优化流程**：支持人工干预的提示词优化循环
- **完整输出**：生成8张基础图 + 4张展示图

## 使用场景

1. 汽车品牌宣传片分镜设计
2. 车型展示图片生成
3. 汽车广告素材制作
4. 多品牌多车型批量生成

## 输出规范

### 基础图片（8张）
- body_front.jpg - 车身前视图（16:9，白色摄影棚）
- body_side.jpg - 车身侧视图（16:9，白色摄影棚）
- body_rear.jpg - 车身后视图（16:9，白色摄影棚）
- wheel.jpg - 轮毂特写（1:1）
- logo.jpg - 车标配饰（1:1）
- sensor_radar.jpg - 传感器雷达（1:1）
- lights_front.jpg - 前灯组（1:1）
- lights_rear.jpg - 后灯组（1:1）

### Showcase图片（4张）

#### bannanapro_showcase.jpg - 香蕉生图用
- **用途**: AI生图平台（无限制）
- **内容**: 所有8张图片的完整展示（3张三视图 + 5张细节图）
- **要求**: 无分辨率限制，无文件大小限制

#### video_showcase系列 - 视频用（严格规范）

**约束条件（必须严格遵守）**：
- ✅ **文件大小**: ≤ 4.7MB
- ✅ **分辨率**: ≤ 4096×4096
- ✅ **最短边**: ≥ 320px
- ✅ **长宽比**: ≤ 3:1

**分类**：
1. **video_showcase_body.jpg** - 车身三视图
   - 内容：前视图、侧视图、后视图（完整显示，不裁剪）
   - 布局：横向拼接
   - 推荐：3944×2480（长宽比约1.59:1）

2. **video_showcase_lights.jpg** - 灯组展示
   - 内容：前灯组、后灯组
   - 布局：横向拼接
   - 推荐：3944×2480（长宽比约1.59:1）

3. **video_showcase_details.jpg** - 细节展示
   - 内容：轮毂、车标、传感器
   - 布局：横向拼接
   - 推荐：3944×2480（长宽比约1.59:1）

**重要**：拼接时必须完整显示图片，采用**缩放**而非**裁剪**

## 技术栈

- **Gemini 3 Pro Image Preview**: 高质量图片生成
- **豆包AI (doubao-seed-2-0-pro-260215)**: 质量分析和优化
- **Python 3.8+**: 核心开发语言

## API配置

- Base URL: `https://www.dmxapi.cn`
- 生图模型: `gpt-image-2`
- 豆包模型: `doubao-seed-2-0-pro-260215`

## 使用方法

当用户需要生成汽车模型图片时，提供以下信息：
- 汽车品牌（如：BMW, Mercedes, Audi）
- 车型名称（如：X3, A4, Model S）
- 参考图片目录路径
- API密钥（Gemini 和可选的豆包）

系统将自动完成生成流程，包括质量检查和优化。

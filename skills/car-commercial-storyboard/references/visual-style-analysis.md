## 风格定义

### 动感奢华风格：动感导向·暖调高对比·中心聚焦

#### 运镜风格

**主导运镜：动态跟拍（68%）**
- **特点**：镜头与汽车同步运动，背景呈现运动模糊
- **目的**：营造强烈速度感和视觉冲击力
- **场景**：盘山公路、隧道、郊野道路

**辅助运镜：特写镜头（20%）**
- **特点**：聚焦局部细节（车灯、车身线条、内饰、材质）
- **目的**：展示精致工艺和材质质感
- **场景**：材质纹理、金属光泽、发光装饰

**场景运镜：航拍俯视（8%）**
- **特点**：高空视角呈现汽车在开阔地面的行驶
- **目的**：展示环境与汽车的尺度关系
- **场景**：沙地、水库、自然景观

**静态运镜：固定机位（4%）**
- **特点**：广角拍摄静止场景，突出品牌标识
- **目的**：营造宁静高级的结尾氛围
- **场景**：结尾品牌标识展示

#### 色彩风格

**主色调：暖色调高对比（44%）**
- **色调特点**：暖光笼罩、夕阳光线、木质暖色
- **对比度**：高对比度，明暗反差强烈
- **目的**：营造活力、激情、温暖氛围

**冷暖对比风格（36%）**
- **冷色调**：隧道冷蓝、雾天冷灰、水体蓝绿
- **暖色调**：品牌色、夕阳金黄、木质暖褐
- **对比效果**：冷底色 + 暖主体，色彩碰撞强烈
- **目的**：突出主体汽车，增强视觉冲击力

**低饱和度风格（12%）**
- **适用场景**：雾天、郊野、自然景观
- **色彩特点**：柔和朦胧、灰调偏冷
- **目的**：营造空旷、未知、神秘氛围

#### 构图风格

**主导构图：中心构图（36%）**
- **特点**：汽车主体居于画面视觉中心
- **目的**：突出主体，强化视觉焦点
- **场景**：动态跟拍、隧道行驶、第一视角

**动态构图：曲线构图（24%）**
- **特点**：以弯曲道路、水岸线、车身流线为视觉引导
- **目的**：展现运动轨迹，增强动感
- **场景**：盘山公路、水库水岸、车身轮廓

**纵深感构图：框架构图（16%）**
- **特点**：两侧树木、隧道、植被形成天然框架
- **目的**：强化纵深感，引导视线向延伸方向
- **场景**：林间道路、隧道行驶、自然景观

**引导构图：引导线构图（12%）**
- **特点**：纵向延伸的道路、车辙、线条引导视线
- **目的**：强化画面纵深感，营造空间层次
- **场景**：郊野道路、沙地车辙、公路延伸

**层次构图：三分法构图（8%）**
- **特点**：前景、中景、远景分层清晰
- **目的**：展现空间层次，构建丰富纵深感
- **场景**：自然景观、沙丘植被、山地天空

#### 整体风格特征

**1. 动感导向（68%动态跟拍 + 运动模糊）**
- 强调汽车速度和驾驶乐趣
- 通过运动模糊和动态跟拍营造冲击力
- 符合高性能汽车的品牌定位

**2. 色彩活力（44%暖色调高对比 + 品牌色）**
- 暖调营造激情和活力
- 高对比度突出主体汽车
- 品牌色作为视觉焦点，强化品牌识别度

**3. 主体突出（36%中心构图 + 20%特写）**
- 汽车始终处于视觉中心
- 特写展示精致细节和材质
- 背景虚化或动态模糊，强化主体

**4. 层次丰富（曲线构图 + 引导线 + 框架构图）**
- 多种构图方式增强视觉层次
- 纵深感营造开阔空间感
- 引导线突出运动轨迹

**5. 品牌识别（品牌色 + 品牌标识）**
- 品牌色作为视觉焦点
- 结尾展示品牌标识
- 强化品牌高端定位

## 分析方法

**使用豆包多模态API进行视频帧分析：**

1. **视频帧提取**：使用ffmpeg提取关键帧（每10秒1帧）
2. **豆包多模态分析**：每帧分析4个维度（运镜、构图、色彩、总结）
3. **风格统计**：汇总分析结果，统计各维度分布
4. **风格总结**：基于统计数据总结整体风格特征

**API配置：**
- 模型：doubao-seed-2-0-pro-260215
- API端点：https://www.dmxapi.cn/v1/chat/completions
- 认证方式：Authorization头直接使用API Key（不加"Bearer "）

**分析提示词：**
```
请从以下维度分析这张视频帧的视觉风格，以JSON格式返回：

1. camera: 运镜方式（航拍俯视/固定机位/动态跟拍/特写/广角等）
2. composition: 构图特点（三分法/曲线构图/中心构图/框架构图等）
3. color: 色彩风格（冷色调/暖色调/冷暖对比/低饱和度/高对比度等）
4. summary: 一句话总结该帧的视觉特征

请严格按以下JSON格式返回（不要包含其他文字）：
{
  "camera": "运镜方式描述",
  "composition": "构图特点描述",
  "color": "色彩风格描述",
  "summary": "一句话总结"
}
```

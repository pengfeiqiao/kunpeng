# 汽车广告运镜模板

本文档定义了汽车广告中常见的运镜方式、特征和适用场景。

---

## 运镜类型

### 1. 航拍俯瞰 (aerial)

**描述：** 从高空垂直或斜角俯瞰车辆和周围环境。

**特征：**
- God's eye view（上帝视角）
- 缓慢推入或平移
- 展现车辆在壮丽场景中的渺小与力量
- 从远景推至中景

**适用场景：**
- 史诗大片风格
- 壮丽自然景观（山脉、峡谷、海岸线）
- 展现路线规划和环境

**推荐提示词：**
```
航拍俯瞰镜头（God's eye view），从高空垂直或斜角俯瞰，
展现车辆在壮丽自然景观中的渺小与力量，缓慢推入，
远景展现宏大场景（山脉、峡谷、海岸线）。
```

---

### 2. 动态跟拍侧面 (chase)

**描述：** 从侧面跟拍车辆，捕捉车辆高速移动的动态感。

**特征：**
- 侧面角度
- 车辆从画面一端移动到另一端
- 低角度跟拍
- 运动模糊效果

**适用场景：**
- 活力动感风格
- 城市穿梭
- 展现车辆性能和速度

**推荐提示词：**
```
侧面动态跟拍镜头，车辆从画面右侧高速移动到左侧，
低角度跟拍，捕捉车轮和车身的动感，
运动模糊效果，展现速度感。
```

---

### 3. 前置跟拍 (lead)

**描述：** 摄影机在车辆前方跟随拍摄。

**特征：**
- 车辆前方的视角
- 感受车辆前行的速度感
- 引擎轰鸣的视觉呈现
- 动态感十足

**适用场景：**
- 活力动感风格
- 速度感、性能展示
- 跑车、性能车广告

**推荐提示词：**
```
前置跟拍镜头，摄影机在车辆前方跟随拍摄，
感受车辆前行的速度感，引擎轰鸣的视觉呈现，
动态感十足，前方道路延伸。
```

---

### 4. 平稳跟拍后方 (tracking)

**描述：** 摄影机在车辆后方跟随拍摄。

**特征：**
- 车辆后方的视角
- 平稳运镜
- 展现车辆行驶的稳定和舒适
- 生活化的场景

**适用场景：**
- 生活场景风格
- 舒适、安全的感受
- 家用车型广告

**推荐提示词：**
```
后方平稳跟拍镜头，摄影机在车辆后方跟随拍摄，
展现车辆行驶的稳定和舒适，平稳运镜，
生活化的场景，家庭出行的温馨感。
```

---

### 5. 特写镜头 (close-up)

**描述：** 聚焦车辆细节。

**特征：**
- 聚焦细节（车灯、格栅、轮毂、内饰等）
- 缓慢推入
- 展现精致的工艺和质感
- 细腻的光影

**适用场景：**
- 豪华质感风格
- 细节展示
- 超豪华品牌广告

**推荐提示词：**
```
特写镜头，聚焦车辆细节（车灯、格栅、轮毂、内饰等），
缓慢推入，展现精致的工艺和质感，
细腻的光影，材质真实呈现。
```

---

### 6. 广角镜头 (wide)

**描述：** 广角拍摄，展现车辆与周围环境的和谐。

**特征：**
- 广角全景
- 展现车辆与环境的和谐
- 广阔的空间感
- 背景清晰可见

**适用场景：**
- 史诗大片风格
- 环境展示
- 展现路线规划

**推荐提示词：**
```
广角镜头，展现车辆与周围环境的和谐，
广阔的空间感，背景清晰可见，
环境作为陪衬，车辆在宏大场景中。
```

---

### 7. 低角度仰拍 (low-angle)

**描述：** 从地面仰视车辆。

**特征：**
- 低角度
- 展现车辆的霸气和力量感
- 车轮和底盘的细节
- 压迫感

**适用场景：**
- 史诗大片风格
- 力量感、霸气
- SUV、越野车广告

**推荐提示词：**
```
低角度仰拍镜头，从地面仰视车辆，
展现车辆的霸气和力量感，车轮和底盘的细节，
压迫感，征服自然的视觉象征。
```

---

### 8. 顶视镜头 (overhead)

**描述：** 垂直俯瞰。

**特征：**
- 垂直俯瞰
- 展现车辆行驶路线
- 全景展示
- 适合展示路线规划

**适用场景：**
- 路线规划
- 展现复杂路况
- 适合展示车辆在特定路线中的行驶

**推荐提示词：**
```
顶视镜头，垂直俯瞰，展现车辆行驶路线，
全景展示，适合展示车辆在复杂路况中的路线规划，
路线清晰可见，车辆在道路中。
```

## 运镜与风格的映射

| 风格 | 推荐运镜 | 原因 |
|------|---------|------|
| `epic` | `aerial`、`low-angle` | 史诗感、力量感 |
| `dynamic` | `chase`、`lead` | 动感、速度感 |
| `luxury` | `close-up` | 细节、质感 |
| `lifestyle` | `tracking`、`wide` | 舒适、生活化 |

## 运镜组合建议

### 九宫格分镜的运镜组合

```
┌─────────┬─────────┬─────────┐
│ 航拍俯瞰│ 车辆远景│ 环境全景│  ← 上行：开场和全景
├─────────┼─────────┼─────────┤
│ 跟拍镜头│ 正面镜头│ 侧面特写│  ← 中行：主体展示
├─────────┼─────────┼─────────┤
│ 内饰细节│ 高潮时刻│ 结尾收尾│  ← 下行：细节和结尾
└─────────┴─────────┴─────────┘
```

### 完整广告的运镜节奏

**开篇（0-3秒）：**
- `aerial` - 航拍俯瞰，建立场景
- `wide` - 广角展示环境

**发展（3-15秒）：**
- `chase` - 动态跟拍，展示性能
- `lead` - 前置跟拍，感受速度
- `tracking` - 平稳跟拍，展示舒适

**高潮（15-25秒）：**
- `close-up` - 特写细节，展现质感
- `low-angle` - 低角度仰拍，展现力量

**结尾（25-30秒）：**
- `wide` - 广角收尾，车辆驶向远方
- `overhead` - 顶视镜头，展现路线

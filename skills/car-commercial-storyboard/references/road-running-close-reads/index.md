# 路跑逐段细读：从相邻镜头到生成描述

这是 [12条片例经验](../road-running-case-lessons.md) 的下一层证据。不要全部读入上下文；先确定本稿问题，读取下表对应的1—2组，再参照 [原创单镜完整提示词](prompt-translations.md)。

## 本轮核对范围与精度

对8支片的8段原始视频重新解码：合计113秒，每0.25秒取样，共452张画面、16页有时间标记的接触表。逐页复核了全部452张画面的相邻变化。源文件编号与哈希沿用 [54片索引](../tvc-2026/index.md)。本轮没有新增模型推断报告。

时间标记是抽样位置，镜头切点通常只能定位在相邻样本之间；短于0.25秒的切镜仍可能漏过，不能声称帧精确EDL。车的大小、可见侧面、背景变化可以比较；真实速度、焦距、设备、全部连续轨迹和声音切点不能由此确认。本页没有把抽帧复核说成完整音画逐帧审核。

表中的“作用、接法、删掉的损失”是有画面依据的编辑分析，不是原导演自述；“提示词与白模参数”是用于新任务的制作建议。

## 一、把“运镜名”改为画面里可验证的变化

| 空泛写法 | 还缺什么 | 具体落笔方式 |
| --- | --- | --- |
| 侧跟，表现车很稳 | 相对距离是否变化，环境有无运动 | 车身占幅基本稳定，轮拱与相机相对稳定，近树比远林更快横掠；稳的是取景关系，不宣称底盘性能 |
| 车迎面而来 | 是相机倒退领拍还是车接近固定视点 | 选择“等距领拍，占幅稳定”或“相对距离缩短，车从小变大”，不要二者并写 |
| 低机位体现速度 | 哪个参照物让速度可感知 | 近路面纹理快速经过、车轮接地区可读、远景变化较慢；不只加8K和模糊 |
| 环绕展示 | 起初看哪一面，最后看哪一面，中间有无切镜 | 从正前逐渐露出一侧，结束仍在侧前；有切镜就拆镜，不能笼统写360度 |
| 航拍气势宏大 | 车与道路、山体各占什么作用 | 保留前方道路弧线，让车成为可定位的小尺度；整车识别由另一个镜头完成 |
| 车身闪过光影 | 光来自哪里、改变什么 | 树冠开口的亮光掠过前挡和上部车身，漆色与轮廓保持，不变成车体发光 |
| 水花扑面而来 | 水从何处产生、何时遮挡、如何结束 | 先可见轮胎接触薄水层，再局部水雾扩散，后段轮胎重新可辨；与路面水量匹配 |
| 动感转场 | 谁的动作在何时切给谁 | 在车辆近处掠过阶段切到新的远景；不是让模型把近车熔化成山体 |

## 二、一个镜头内部也有叙事

写三个**文字状态**，无需首尾帧图片或新按钮：

- **入镜时已经成立什么**：车在本车道、车头指向哪边、看清哪一面、场景与前镜保持什么。
- **持续变化是什么**：相对距离、侧面显露、视差、遮挡、光线或接触反馈；选一个主变化，其他保持。
- **在什么状态切走**：掠过近处、进入下段弯道、露出完整侧面、尘雾消散、乘员完成动作；不一定停车，不一定落版。

例如C01的逼近镜：起初远处小车与弯道同框；中段车朝近处走、占幅扩大；末段车穿过近前景。下镜改为大景远去，观众从压近转向放开。若把这一镜写成“相机始终等距跟随”，就删掉了它最重要的变化。

## 三、相邻镜头不是只靠“同向”衔接

1. **空间连续**：同一段行驶的下一阶段，必须核对行车方向、入/出弯、太阳侧、道路干湿和乘员。适合动作顺接。
2. **尺度跳转**：从车脸到山谷，或从大路到轮胎；依靠同一对象/动作延续，不要求同一机位连续变焦。C01、C04。
3. **观看关联**：有人看向一个方向，下一镜给车或路；新稿须明确视线与位置，原片有反应不等于已证明人物动机。C05。
4. **形态/材质关联**：茶叶与路面叶片、人体展开与车辆水花；两边各自完整，通过剪辑连接，不自动变形。C02、C03。
5. **节奏反差**：短促经过接较长静态动作；静与动相互定义。C07、C08。
6. **旅途省略**：路跑接目的地活动，可省掉全部停车流程；若会导致误解行车中做危险动作，补一个停稳的明确条件。C06。

同一段只选一两个主连接机制。不要每个切点都加甩镜、遮挡、光闪或特效；普通硬切也可以清楚成立。

## 四、文案不要挤占镜头已经做的事

- 镜头已交代地理时，不再用VO念“我们开在山路上”。让台词/VO补动机、关系或时间；没有新信息可以留白。
- 人物把动作做完，比旁白宣布“从容”更具体。C08的喝茶动作不必拆成五句形容词。
- 路跑表现的是可见行进，不是续航、舒适性、操控或安全测试。产品句子必须有另行确认的资料。
- 旁白节奏不能机械等分到每个镜头；一句可以跨两镜，但这是新稿配音方案，不能宣称原片就是如此。

## 五、把分析转换为现有产品字段

**文案分镜行**写“本镜目的＋可见动作＋机位变化＋剪辑接点”；按现有表结构分配，不要求全部塞进一列。研究来源和推断留在备注/内部依据，不进角色对白。

**工坊单镜提示词**只保留该镜所需场景、车型、人物和动作，不带下一镜的场景命令。**画布局部编辑**先声明保持项，再改本镜的主变化。**普通对话**若只是讨论怎么写，交付解释与文本，不自行生成。

**Blender规格**再展开米、秒、目标点和相对路径；文字分镜不必背坐标。跟随、固定、接近与超越分别设置，不把整个片段的所有机位合并成一条相机动画。最终视觉的材质、反射、液体、尘雾与人物必须另验证。

## 六、本轮新增纠偏

- TVC41约15.5—17.25秒是茶叶落入壶口，之前“倒茶”容易误解为倒水；正式参考已改为“投茶”。
- TVC01约14—17.5秒含座舱/入座与乘员展示，不应笼统都标为连续驾驶；新稿不能在正常行驶中安排入座、换座或解开安全带。
- TVC53约32.25—33.75秒的倾斜画幅不是车辆失控侧倾的证据。
- TVC39城市段看见了行人遮挡和车头，不能把“旁观反应”写成所有行人赞叹，更不能生成近距离危险擦碰。

优先级：用户已定事实与修改范围→本轮细读证据→前轮概括→原始模型辅助报告。细读与旧描述冲突时用更具体证据修订，不把两个版本都当事实喂给模型。

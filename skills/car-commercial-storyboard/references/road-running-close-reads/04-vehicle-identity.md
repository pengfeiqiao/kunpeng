# C04 · 案例 TVC01：双车型切换时，机位承担身份辨识

来源：[TVC01片例](../tvc-2026/TVC01.md)，原片3.00—19.00秒，4fps抽样。各行是可见片段，不把多车型拼成单车连续动作。

| 观察窗 | 画面层次与运动结果 | 本镜增加的信息 / 与下镜的关系 |
| --- | --- | --- |
| 3.00—3.50 | 湖在一侧，崖壁在另一侧，道路为狭长引导线，车很小 | 地理限制与路线清楚；先看环境，不要求此处读清灯组 |
| 3.75—5.00 | 深色车从较正前逐渐露出更多侧面，背景岩壁形成横向流动 | 看清前脸、轮拱与车侧的连接；**相对视角确实变化，不能写成固定正前同速镜**，但变化不足以推定完整环绕 |
| 5.25—7.00 | 顶视林冠与道路，车在窄路上前进 | 从车的体量退回路线尺度；顶视和前视是切镜，不是相机一口气升空 |
| 7.25—8.00 | 头枕标识与座椅/扶手细节先后出现 | 外部身份进入内部材质，二者是短局部镜，不是同一部件连续变形 |
| 8.25—9.50 | 驾驶人物中近景，窗外树林流动 | 路途获得人物视角；新创作保留正确佩戴安全带，不从此段推定人物姓名 |
| 9.75—10.50 | 浅色车前部较高俯视近景，前灯与标识可辨 | 新车型/新身份的识别点；不能沿用上一辆车资产再让它自动变色变形 |
| 10.75—11.75 | 浅色车完整侧面，背景和近前景横移，车在画内相对稳定 | 补足前一近景没有的车长与顶线；在“前脸→侧面”之间积累车型认识 |
| 12.00—13.75 | 深色车正前，画面带倾角，道路与绿植向后流动 | 回到另一身份和动态姿态；画幅倾斜不能翻译成车辆悬空或异常侧倾 |
| 14.00—17.50 | 驾驶位、仪表台、副驾、后排人物依次被呈现 | 这是座舱/乘员段落；部分观察角连续变化，但不能用抽样保证全段一镜或虚构家庭关系 |
| 17.75—18.75 | 深色车前侧近景，岩壁与反射变化 | 从内部体验回到可辨外部身份，闭合这组内外关系 |

## 具体经验

它不是“航拍—人—车—人”的随机拼接：道路告诉位置；近前脸给识别；侧面补比例；人物与材质改变观看对象；再回整车。浅色和深色车型交替靠各自可辨特征维持，单靠文案写“同一辆车”反而会破坏原片的产品逻辑。

新稿如果只有一辆车，应借用这种信息分工，**删除双车型切换机制**。如果确有两辆车，在镜号中明确资产A/B，分别锁定车色、前脸、轮毂和内饰，不把两车参考同时交给一个镜头而不说明用途。

## 从观察转成可生成描述

“侧前领拍”需要进一步明确：本镜是否让可见侧面逐渐增多？若是，写相对角度有小幅变化，并允许车在画内轻微位移；若不需要，才写相对方位固定。身份展示镜应减少树干对关键灯组的长期遮挡，触感镜可以暂时舍弃完整车身。

**原创分镜句：**“上一镜已用湖岸道路建立去向；本镜完整前脸进入，随后逐渐显露车的一侧，车头与前轮都留在画内；下一镜独立切到侧面，以同一资产确认顶线和车长。”不要把两个镜号压成模型自行剪辑的多机位命令。

白模可验证前侧角度变化是否过大、完整侧面能否入画；车标、灯组和内饰的身份依然靠定版资产，不由代理车体证明。

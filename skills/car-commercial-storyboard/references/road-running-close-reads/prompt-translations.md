# 拉片经验如何变成完整单镜提示词

以下8条是原创转译，不是原片镜头参数或原文。每条均可单独作为编辑底稿；真正提交前用当前工具实际附件协议绑定参考，不能只写“参考车”却没有挂载素材。单镜不自动执行付费生成，不要求首尾帧；时长和比例以用户简报及工具能力为准。

正文不强制填写焦距、车速等无法验证的数字。需要白模时再设建议参数，并标明非原片测量。

## P01 山路逼近：把相对距离变化写清楚

**依据与改编：**C01 / TVC53，接近与远去的分工；下文为原创单镜，不复制原路况。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车在干燥铺装弯道远处出现，完整车身起初较小，弯道出口和前方车道同时可见。摄影机位于道路外侧的固定观察位置，不与车等距后退；取景保持水平，车沿本车道弧线逐渐接近，前轮随弯道转向，车头方向与路径切线一致。随距离缩短，整车在画面中逐渐变大，前脸与一侧轮拱先后可读；车辆继续经过近前景，车身穿过取景区后结束，不在镜头前突然刹停，不甩尾。轮胎持续接地，路旁山体保持稳定，近处车身经过时允许自然运动模糊。

**剪辑关系：**上一镜若已交代车型，本镜不再加标识特写；下一镜可以独立拍山谷远去。

**验收重点：**比较入、中、末：是否由小到大、道路是否固定、经过后是否出画；等大锁中说明相对关系写错。

## P02 林间穿行：遮挡要有进入和恢复

**依据与改编：**C02 / TVC41，完整车→树干遮挡→接触细节的层次。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车沿平整林间道路向画面右侧匀速前进。摄影机在车左侧平行移动，保持相对距离和高度，完整侧面位于画面中部。取景前方有间隔疏朗的近处树干，近树向左较快掠过，远林移动较慢；每次遮挡只短暂盖住车身的一部分，车在树干之间重新完整显露。车前留出前进空间，镜头不绕到另一侧。树冠间的柔光在车顶和侧面形成连续明暗变化，车漆颜色与轮廓保持不变；路面干燥，不新增泥水和巨大烟尘。结束时车侧再次清楚可见，车辆仍沿原路前进。

**剪辑关系：**轮胎近景另建镜号，不让本镜突然钻入轮拱。

**验收重点：**至少检查两次树干遮挡前后能否辨认同一辆车；近远背景不可像一张壁纸同速滑动。

## P03 浅湿路接触：能量出现后恢复可读

**依据与改编：**C03 / TVC25，学习遮挡阶段，不搬用原片的大水幕。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车沿已有薄水膜的平直铺装路面稳定前进。摄影机位于左前轮外侧，低位平行同速跟随，取景包含轮胎、轮拱和一段路面。起初轮胎与接地区清楚可见；轮胎进入局部浅水膜后，细小水滴从接触区域向后外侧散开，短暂遮住轮胎下缘；车辆继续前进，水滴落下后接地区重新可辨。轮拱与相机相对稳定，路面纹理向后流动。阴天漫射光与路面有限反射一致，不出现淹没车头的大浪，车身不漂浮，不切成航拍，不要求所有轮辐每帧静止清楚。

**剪辑关系：**此镜负责触感；前后至少一镜负责完整车身识别。

**验收重点：**水从接触区产生、随车经过而减少；不能从车顶凭空喷出或始终贴着镜头不消散。

## P04 前脸到侧前：变化有限而明确

**依据与改编：**C04 / TVC01，前视逐步显露侧面的观察，而非固定正前或完整环绕。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车沿直道平稳前进。摄影机从车辆前方偏左的观察位置开始，同向移动并逐渐增加左侧偏移，始终处于车头前侧的外部空间，不跨过车头中轴或穿入车体。开头以前脸为主，中段逐渐显露左侧前轮与车门前部，结束在清楚的左前三分之四视角；只完成这一小段视角变化，不绕到车尾。车辆保持本车道，不能为了显露侧面突然横向转动。车身占幅允许轻微自然变化，前灯、前轮与车顶持续留在画内，周围环境反射随行进变化。

**剪辑关系：**若需展示完整正侧面，另起一镜；双车型项目必须明确本镜绑定哪一辆。

**验收重点：**看的是相机与车相对角度变化；车头仍指向道路前方，不能整辆车原地旋转。

## P05 城市经过：有路口和前景，但不危险擦碰

**依据与改编：**C05 / TVC39，经过、前景层次与观察者的注意链。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车在城市街道沿本车道平稳前进，车头朝画面右侧。摄影机从街道一侧沿街道同向缓移，速度低于车辆，保持整车侧面可辨，取景包含一段前方路口和远处建筑立面。近处路灯柱从画面边缘短暂掠过，不长期盖住前灯或整车；远处立面变化较慢，车身玻璃与车漆反射对应经过的建筑。人行道上的既有人物保持在人行区域，与车辆道路分开，不进入车辆行驶轨迹。车经过路口取景范围并逐渐离开，镜头不突然环绕或冲上人行道。结束保留少量街道画面，供下一镜接人物自然转头。

**剪辑关系：**“人物转头”是下一镜的编辑意图，不要求当前生成视频自动插入特写。

**验收重点：**检查车道、人行道和柱体前后层；人物不能与车体穿插，建筑不能随车一起横移。

## P06 海岸远景：让路途容纳安静

**依据与改编：**C06 / TVC38，座舱小动作与海岸大空间交替。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车沿贴近海岸的铺装道路平稳前进。摄影机位于道路侧上方，斜俯观察，山壁在一侧、水面在另一侧，保留前方完整弧形道路；车辆在画面中较小但行进方向明确。取景保持平缓，车辆沿道路弧线位移，摄影机不急速追近、不俯冲车窗、不在空中翻滚。暮色天空与水面层次可辨，车辆灯光范围有限，不把整车画成自发光体。结束时车辆继续沿前方道路行驶，海岸与道路仍然可读。

**剪辑关系：**前镜可为乘员安静动作，后镜再回人物；本镜不用同时展示灯组内部细节。

**验收重点：**车不能小到完全无法定位；道路要连续可通行，车不能跨护栏开上海面。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车沿开阔地面上一条明确的平缓土路向前行驶，保持车头与道路一致，不侧滑、不原地画圈。摄影机在车辆侧后方沿平行路径移动，始终看见完整车身及后方一段道路。少量干尘从轮胎接触处扬起，离开接触点后逐渐滞留和扩散，车继续前进，尘尾落在行驶路径后方而不是固定黏在车尾。近处地面纹理移动较快，远山缓慢变化；尘带高度有限，不持续吞没整车。结束时车辆轮廓仍可辨，道路与轮迹延续同一方向。

## P08 短路跑脉冲：驶过即可结束

**依据与改编：**C08 / TVC12，短运动与较长人物动作之间的节奏反差。

**完整提示词底稿：**

以本镜实际挂载的定版参考车为唯一身份依据，保持车身比例、车漆、灯组、轮毂和已确认配置，空间参考不替换车型。已有驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧；遮挡不改变佩戴事实，纯车外取景不新增可见人物。不新增字幕或水印。定版车沿茶田之间的铺装道路驶过，开头为清楚的侧后方整车，取景留出道路前方，背景茶垄沿地势展开。摄影机保持道路侧面偏后的观察位置，不始终追住车辆；车持续沿路离开，相对距离逐渐增大，车由较大变小。轮胎接地，车辆不换道、不加漂移，柔和日光与车漆反射保持一致。车尾进入远处一段道路后结束，不额外升空、不转到车内、不加入人物举杯。

**剪辑关系：**将这段运动素材剪在室内人物动作之间；生成长度依工具支持范围，剪辑长度另定。

**验收重点：**车是否真的远去；如果始终等大，应改相对机位而不是只把播放速度加快。

## 输出到分镜表时的压缩方式

把提示词压缩成“镜头目的—画面动作—车辆/相机关系—结束接点”，而不是逐字塞入表格。例如P01：

> 本镜制造接近感。定版车沿宽弯由远驶近，摄影机在道路外侧固定观察，车占幅逐渐扩大，车头随路径转向；近处掠过时切走，下一镜独立转山谷远去。

车型、安全带与道路连续性放入该镜实际生成提示词及既有制作设定。压缩不等于删除提交时的保持项。

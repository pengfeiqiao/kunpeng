# C03 · 案例 TVC25：先让对象可读，再用水花打断可读性

来源：[TVC25片例](../tvc-2026/TVC25.md)，原片51.00—66.00秒，4fps抽样。以下部分行合并短蒙太奇，不将其伪称为一个连续镜头。

| 观察窗 | 可见事件和尺度 | 运动判断与接法 |
| --- | --- | --- |
| 51.00—51.50 | 车后部在草地轮迹上前进，整车可读 | 道路纹理向近处展开，先确立车辆与地面 |
| 51.75—52.25 | 舞者伸展，随后方向盘局部 | 两次对象切换；动作方向可被借用为节奏关联，不是人体变成方向盘 |
| 52.50—54.25 | 前脸较大、地表飞溅；随后的采样中车转为侧前关系并逐渐变小 | 可见观察角与距离在改变；只凭抽样不命名真实拍摄rig，也不保证中间没有更短切点 |
| 54.50—57.25 | 户外、棚内舞蹈快速交替，身体伸展、转身和倾身 | 人物的动势承担节拍，车辆暂时退出；不是每个鼓点都必须有车 |
| 57.50—59.75 | 斜俯视看车辆接近湿地，水雾逐步扩大，后段遮住不少车身 | 有“可读车→局部遮挡→较强遮挡”的阶段；水不是第一帧就罩满画面 |
| 60.00—61.50 | 极近水花与局部轮胎，颗粒/液滴占主要画面 | 是新的近景，不是前镜突然无限放大；对象识别暂时让位于触感 |
| 61.75—63.00 | 车轮及侧裙重新清楚，水花减少，接地区可读 | 重新给机械与接触关系，结束遮挡，不让整段变成无对象的特效 |
| 63.25—65.50 | 户外舞者与棚内群体重新交替 | 从轮胎动作转回身体节奏，不替车增加新的性能宣言 |
| 65.75 | 高位斜前取景再看整车 | 仅确认下一镜重新回到完整车身，后续时长未在此窗统计 |

## 本段真正可迁移的结构

**识别→能量释放→短暂失去细节→重新识别**。它能让水花近景有冲击，因为此前和此后都有车的依据。如果每镜从头到尾都写“巨大水花淹没全车”，观众会失去产品；如果每帧都强制车标和轮毂绝对清楚，又会抹掉触感镜的作用。

这是一种编辑选择，不是给所有雨路增加大水幕的许可。普通雨后路跑应降低水量，保持浅水膜与轮胎接触相称；本片视觉不能证明车辆涉水深度。

## 分镜应拆在哪里

- “整车经过湿地”是一镜，写接近、接触、飞溅扩大及结束状态。
- “飞溅局部”另列镜号，写取景面积和可见轮胎边缘，不让模型生成整个路段。
- “恢复车轮与接地区可读”可以独立取材，也可作为前一近景后段，但先明确是连续动作还是另一次切镜。
- 舞者有自己的动作、空间和镜号；只有用户简报本就需要人物运动时才采用，不为套片例增加角色。

## 原创提示词的重点

不要写“炫酷溅水、动感转场”。应写“前半段能看清车头；轮胎进入已有的薄水层后，少量水从接触区向后外侧散开；随后水雾落下，车轮轮廓重新可读”。该句是降强度的原创建议，与原片水量不同。

白模只验证机位、车辆路径和前后可见区间；液体遮挡需在支持的制作环节单独验证。没有水模拟时，不把灰模视频标作已完成水花表现。

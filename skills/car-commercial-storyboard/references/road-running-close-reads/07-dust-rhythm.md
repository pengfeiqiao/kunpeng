# C07 · 案例 TVC08：尘雾有出现、遮挡、消散与重新识别的过程

来源：[TVC08片例](../tvc-2026/TVC08.md)，原片39.00—55.00秒，4fps抽样。此处有特殊驾驶视觉，不能据成片推断真实性能，不把它当普通公路行驶规范。

| --- | --- | --- |
| 39.00—40.00 | 车尾沿笔直公路远去，两側旷野与远山清楚 | 先有明确方向与可读空间，车从较大变小 |
| 40.25—41.50 | 静态车尾与人物同框，人物手臂动作变化，天际线稳定 | 暂停驾驶动作，人物的动作作为动态段落之间的连接；不能由剪辑推断手势遥控车辆 |

| 44.25—44.50 | 方向盘手部短近景 | 插入控制动作，缩短大尘雾后的识别中断；不由此测量车速 |

| 46.75—48.00 | 更高后向取景，车向远处走，尘尾向近处铺开 | 与先前横向段不同，纵深给尘尾长度一个读法 |
| 48.25—49.75 | 逆光侧面车与较低尘带，近地纹理快速经过 | 重新可见整车轮廓，横向速度感和纵深段轮替 |
| 50.00—52.00 | 人物上身、脚步接地、手持物件三个局部/中近景 | 车的动态暂退，人的身体与地表发生联系；不是无关“美女镜头”填充 |
| 52.25—54.00 | 车辆近处掠过后尘雾与整车再次在远处可辨 | 动态再进入，先前停顿让这一轮运动有重启感 |
| 54.25—54.75 | 人物侧脸与逆光地表 | 回到人的感知；不推定人物内心独白 |

## 具体经验

路跑段不是匀速增加刺激，而是**方向清楚→人/车停顿→遮挡增加→重新定位→换尺度→人物接地动作→再次运动**。真正能迁移的是识别节奏和层次。若只抽取“大片扬尘”作为提示词，便丢掉了前后的可读对象与停顿。

不能因为尘雾遮住车，就要求模型每帧都透过尘雾画出清晰轮胎；也不能因为遮挡很有力，就让身份展示镜全程不可辨。先明确本镜是在展示身份、给触感还是制造短暂遮挡。

## 新片如何借用而不照搬

普通非铺装道路场景，可改为少量接触尘和稳态前进，不需要滑移：整车镜先看路线，局部镜看轮胎附近的小尘，下一整车镜重新确认轮廓。人物停顿可使用用户已写的检查行李/眺望目的地，不复制原片的人物手势、服装和道具。

“尘土从轮胎接触区域产生，已离开接触点的尘粒逐渐滞后、扩散，车继续沿原路径前进”比“后方一个巨大烟团跟着车跑”明确。若有风，写清它对尘尾的影响，但不要与车辆前进方向互相矛盾。

## 白模限制

车辆路径与机位可以预演，漂移、轮胎滑移、尘雾流体和惯性不能靠当前平面滚动实现。不要把“路程/半径”的滚动公式用于声称真实特技复刻完成。反射、粒子和特殊驾驶另需制作方案与用户意图。

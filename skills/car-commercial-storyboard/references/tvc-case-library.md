# 汽车 TVC 案例库（8 条真实案例分析）

8 条国产新能源 TVC 风格样片（越野 SUV、城市 SUV、大六座、轿跑、MPV 全覆盖）的逐条拆解。
用途：写汽车路跑/展示/广告提示词时的语法参照——按车型与气质选最接近的案例，套用其段落结构与镜头语言。

## 案例 1：硬派越野 SUV（雪山远征）

- 开场：俯拍雪原森林（纯环境大远景）→ 雪山群峰大横摇，史诗感建立
- 路跑：低机位侧面跟拍（前轮、保险杠、悬架行程压低入画，车速感靠背景流动）
- 细节：机盖与大灯的行进间近景（漆面反射环境光）
- 留白：山谷索桥航拍大远景（车小点过桥，绿色山谷为主体）
- 人物：登山靴踩雪的特写（生活方式点缀，不露脸）
- 语法要点：**先环境后车**，越野气质靠"大景观里的小车"而非肌肉特写堆叠

## 案例 2：城市豪华 SUV（暗调科技感）

- 开场：LED 灯管暗场阵列（抽象灯光装置）→ 海上日落空镜
- 内饰：车门开启仪式感 → 白色座舱全景
- 路跑：低机位侧跟（轮毂特写占画）+ 卖点字幕（"全栈自研智慧底盘"）；高架桥下逆光路跑；车头低角度城市穿行（车顶激光雷达可见）
- 语法要点：**城市场景用暗调与逆光做高级感**；智能卖点交给对应部位特写（雷达、底盘）而不是全景

## 案例 3：大六座家用 SUV（云海诗意）

- 开场：暗场渐变 → 云海翻腾大空镜
- 细节：车载 音响单元特写（卖点字幕"已确认的车载音响"）
- 内饰：橙色六座全景（天窗采光，字幕"超宽体大六座"）
- 落点：人物与车在草原云海前的合影（人的渺小衬车的可靠）
- 语法要点：**家用定位用大留白与诗意空镜**；音响/座椅这类舒适卖点用材质级特写

## 案例 4：轿跑（荒漠史诗）

- 开场：雅丹荒漠大远景（红色车在蜿蜒路上是小点）
- 路跑：岩壁夹道间穿行远景（车与巨岩的尺度对比）
- 细节：车尾品牌特写（贯穿尾灯+字标，字幕"已确认的驾驶辅助系统"）；车头俯角车标+贯穿灯带
- 呼吸点：沙漠蜥蜴空镜（环境生物转场）
- 语法要点：**轿跑的速度感用长焦压缩与荒漠纵深**；智驾卖点绑定车头/车尾品牌特写

## 案例 5：豪华 MPV（风光巡游）

- 开场：虚焦光斑 → 大理城镇与山海航拍
- 路跑：山路正面迎镜跟拍（字幕"5.3米全尺寸车长"）
- 细节连击：定版轮胎+密辐轮毂（字幕"磁流变悬架"）→ 格栅星瀑灯带特写（字幕"贯穿式星瀑灯带"）→ 打孔真皮座椅特写（字幕"16点气袋按摩"）
- 语法要点：**卖点密集时用"细节特写+单条字幕"的节奏连击**，每个特写只讲一件事

## 案例 6：红色轿跑（高原湖泊）

- 开场：晨雾湖面虚焦（车在雾中色块）→ 暗场 → 大光斑
- 细节：打孔皮座椅在光影里的特写（光比大、材质为王）
- 路跑：高原湖泊公路大远景 ×2 角度（红车是蓝色世界里唯一的暖点）
- 语法要点：**单一强色车身配冷色大景观**，颜色对比就是构图主角；少即是多

## 案例 7：家用 MPV（家庭叙事）

- 叙事：父亲翻看孩子照片（剧情开场，车未出现）→ 侧滑门开、白色内饰、孩子上车 → 车内家庭互动（天窗采光）→ MPV 侧面静展（庭院松树）→ 城市路跑
- 语法要点：**家庭定位先讲人再讲车**；车第一次出现用"开门"动作而不是直接展示；侧滑门是 MPV 的仪式感镜头

## 案例 8：科技 SUV（草原征途）

- 细节：车尾特写（ISC 交互尾灯区域）
- 路跑：草原土路航拍跟车（扬尘、蜿蜒、大地曲线）
- 内饰：中控大屏 UI 特写（温度/座椅调节界面）→ 内饰材质近景 → 脚踏特写
- 语法要点：**科技感绑定屏幕 UI 与尾灯交互细节**；土路扬尘航拍是"轻越野"气质的标准镜头

## 跨案例共性（写提示词时的检查表）

1. 开场必有一个"非车"镜头：暗场、光斑、大空镜——先建立世界再请出车
2. 路跑三件套至少用两件：低机位贴地侧跟 / 正面迎镜 / 航拍大远景
3. 细节特写永远单主体，一个镜头只卖一个点
4. 黄金时刻/蓝调时刻优先，正午平光禁用
5. 车与景观的构图关系：意境镜头车小景大，展示镜头车大景虚
6. 转场用环境空镜呼吸（云、光斑、动物、扬尘），不镜镜是车
7. 字幕是剪辑层的事，生成画面保持无字

# 汽车图像、视频提示词与制作连续性

先读 [从拉片中提炼的12条路跑分镜经验](road-running-case-lessons.md)，按本稿目的选择片例关系，再使用机位模板；保留证据与推断的区分。

具体分镜和路跑提示词优先读 [分镜与路跑执行方法](road-running-shots.md)：含七类单镜正文、完整段落分镜、冲突检查与白模对应。

先读文案意图，再决定画面。不要用“电影感、8K、史诗、顶级广告”代替机位、动作和光源。

## 任务与素材分层

1. **车辆身份**：定版参考、车型版本、颜色、车身比例、轮毂、灯组、格栅、标识和真实传感器配置。看不见的部位待确认。不能把不同参考里的相近车揉成新车。
2. **外观资产**：按镜头需要建立正前、正侧、正后及必要细节，每张独立输出；用户要三视图才交付完整三张。不因为技能默认就先花钱生成全套细节。
3. **空间参考**：构图板/白模提供位置、遮挡和相机路径，不负责车漆与身份。
4. **运动参考**：保留镜头/视频的实际映射，不能把视频冒充图片编号。引用在所用工具提交顺序内校准，不硬编码 @视频1 永远是白模。
5. **文字层**：产品文案单独留在脚本或后期说明。生图/视频默认不新增字幕、水印或随机车牌字；用户明确要求时另行处理。车标不是应被删掉的随机文字。

## 单张图像的写法

一个瞬间：同一参考车 + 具体动作状态 + 场景与可见空间关系 + 机位/构图 + 光源/反射 + 必要连续性。

不用“先航拍、再推近、最后特写”描述一张图。低机位并不等于超广角：可用适度距离保持轮距与车身比例，透视强弱由构图需求决定。静态资产棚拍和外景主视觉分别写，不能同时要求无缝白棚、峡谷背景和满身城市霓虹反射。

## 时间镜头的写法

先说明起始车位、道路走向、车头朝向、画面运动方向；再分别描述：
- 车：起点→路径→终点，直行/弯道/停靠、速度与加减速阶段。
- 相机：在车前/后/侧、相对车的距离和高度，固定/同步跟随/超越/被车驶过，焦点目标。
- 可见结果：背景视差、车在画面里的大小变化、轮胎滚动、转向、车身受力、尘水从接触点产生。
- 结束状态：哪一动作/视线/空间信息给下镜接点。并非要求生成首尾帧。

镜头数量服从信息与表演，不能用 30 秒必须 8—12 镜作为硬限制。单段一种主运动；组合运动要有清晰分段，不同时要求静止和环绕。

## 场景判断

| 场景 | 画面要解决的问题 | 连续性重点 | 禁止自动推导 |
| --- | --- | --- | --- |
| 城市通勤/高架 | 人、车与建筑尺度；窗口/桥柱遮挡形成视差 | 车道、路口、屏幕方向、交通参与者位置 | 空城、任意逆行或辅助驾驶等于无人驾驶 |
| 棚拍/造型空间 | 让光沿曲面显出车身设计 | 光源形状与位置、漆色、曝光连续 | 紫橙色就是高级、暗到看不清就是豪华 |
| 林间/山路 | 路径在纵深中可读，车速与弯半径可信 | 阴影变化、前后车距、弯道切点 | 所有弯道都漂移 |
| 海岸/湖边 | 风、水、人物活动与车的关系 | 地平线、倒影、湿地接触、逆光 | 风景空镜越多越有情绪 |
| 沙漠/荒地 | 地表反馈与轮胎、路径和尘尾相连 | 接地点、风向、尘尾滞后、路面可通行性 | 扬尘等于越野性能实测 |
| 雨/雪/夜 | 让车身轮廓、反光和路面仍可辨 | 灯光照射范围、接触、刹车距离与曝光 | 随意涉水深度、积雪抓地承诺 |
| 座舱/亲子 | 人物动作和视线、座位空间真实 | 主副驾、头枕、手部、后视镜、乘员约束 | 每个家庭必为三人、后排人物瞬移 |
| 节庆/地域 | 具体习俗活动和当代使用关系 | 时节、服装、生活道具、地点 | 红金装饰代替文化、民俗猎奇 |
| 技术演示 | 可观察结果与操作前提对应 | 操作步骤、状态变化、屏幕内容依据 | 成片画面证明未经核实的功能 |

## 安全带是驾驶画面的硬要求

凡有人驾驶，最终正向提示词必须明确：**驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧**。改风格、改机位、局部编辑和连续镜头都保留；英文须明确同义表述。近景可见处正确呈现，遮挡时仍保留佩戴事实，不为露出安全带强改构图。儿童按故事已有年龄与座位安排适当乘坐约束，不胡编车辆配置。无人车辆空镜不新增驾驶员。

## 工坊与画布

四套制作设定分别存：导演（主导机制/视觉选择）；角色（乘员身份与位置）；场景（空间、时段、道路）；连续性（车身份/方向/灯光/乘员/素材映射）。局部修订只能改对应字段，不清空其他类别。

工坊拆解按原剧本事实建立资产和镜头，车是稳定资产、镜头是对它的不同观察。不可把用户参考图当新生成候选资产；只改提示词时不生成。修改车漆、轮毂或内饰后明确受影响镜头，不能静默让旧外观继续进入后续生成。

画布沿既有节点与连线迭代：确认目标节点及引用，再改该节点提示词；原有候选和身份参考不因画面润色被替换。多个机位复用同一身份资产，但每镜只载必要参考，避免互相冲突。白模挂视频运动参考，资产挂外观参考，不能把灰模涂成最终外观。

## Blender 转译

读 blender-clay-previz 的汽车参数协议。世界坐标统一 X 前、Y 左、Z 上，单位米；车路径与相机路径分开。同步跟车保持相对距离，但环境必须有可见参照才能判断运动；超越镜头改变相对纵向偏移，不能把车和相机一起停在原地。

轮转角用行驶路程/半径；转向随路径曲率，锐角路径应先平滑，不能让车横移拐直角。曲线路径用足够密集采样验证朝向连续。外观白模只需车身/座舱/四轮的正确包络，不伪装成精确品牌 CAD；需要精确内饰、开门或乘员时另建对应空间代理，不让粗盒子承担未实现的动作。

先低分辨率渲染，核对起中末及转弯关键帧、轮胎接地、前进方向、机位穿模、主体出画和遮挡，再交付 .blend 与视频。这里是运动预演，不是汽车动力学仿真；反射/材质/悬架真实效果需要另行制作。

具体到相邻镜头的推敲，读 [路跑逐段细读](road-running-close-reads/index.md)；需要可独立提交的文本底稿，读 [8条完整提示词转译](road-running-close-reads/prompt-translations.md)。

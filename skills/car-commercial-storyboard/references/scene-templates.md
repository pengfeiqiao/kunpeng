# 汽车广告场景模板

本文档定义了汽车广告中常见的场景类型、特征和推荐风格。

---

## 场景类型

### 1. 海岸线场景 (coastal)

**地理特征：**
- 海边公路、沿海高速公路
- 海滩、 cliffs、悬崖
- 港口、码头、渔村
- 海浪、天空、海洋元素

**视觉元素：**
- 蓝色系（海洋、天空）
- 金色阳光（日出、日落）
- 海浪、飞鸟
- 海边公路的曲线

**推荐风格：**
- `epic` - 史诗大片，展现壮丽海岸线
- `lifestyle` - 生活场景，展现家庭海边旅行

**推荐运镜：**
- `aerial` - 航拍俯瞰海岸线和车辆
- `wide` - 广角展现海岸线全景

**示例提示词：**
```
特斯拉Model S沿着加州1号公路的海岸线行驶，
夕阳西下，金色的阳光洒在车身和海面上，
航拍俯瞰视角，展现壮丽的海岸线和太平洋背景。
```

---

### 2. 山地场景 (mountain)

**地理特征：**
- 山脉、高原、峡谷
- 盘山公路、隧道
- 森林、草甸、雪峰
- 云雾、日出、日落

**视觉元素：**
- 灰色、棕色（岩石、山脉）
- 绿色（森林）
- 白色（云雾、雪）
- 金色（阳光、日出）

**推荐风格：**
- `epic` - 史诗大片，展现壮丽山脉
- `lifestyle` - 生活场景，展现山野探险

**推荐运镜：**
- `aerial` - 航拍俯瞰山脉和车辆
- `chase` - 动态跟拍，展现车辆在山路上的性能

**示例提示词：**
```
保时捷911穿越阿尔卑斯山公路，
盘山公路蜿蜒在雪山之间，
航拍俯瞰视角，展现壮丽的山脉和车辆的渺小与力量。
```

---

### 3. 城市场景 (urban)

**地理特征：**
- 城市街道、摩天大楼
- 高速公路、立交桥
- 霓虹灯、夜景
- 都市地标

**视觉元素：**
- 灰色、蓝色（建筑、天空）
- 多彩霓虹灯
- 车辆灯光、路灯
- 城市天际线

**推荐风格：**
- `dynamic` - 活力动感，展现城市穿梭
- `luxury` - 豪华质感，展现都市精英生活

**推荐运镜：**
- `chase` - 动态跟拍，展现车辆在城市中的穿梭
- `wide` - 广角展现城市天际线

**示例提示词：**
```
宝马M4在东京街头穿梭，
霓虹灯闪烁的夜景，车辆在摩天大楼之间穿梭，
动态跟拍镜头，展现车辆的性能和城市的繁华。
```

---

### 4. 沙漠场景 (desert)

**地理特征：**
- 沙漠、戈壁、荒野
- 沙丘、岩石、干涸河床
- 烈日、风沙
- 孤独、苍茫

**视觉元素：**
- 橙色、黄色（沙子）
- 蓝色（天空）
- 棕色、灰色（岩石）
- 光影强烈

**推荐风格：**
- `epic` - 史诗大片，展现苍茫沙漠
- `dynamic` - 活力动感，展现越野性能

**推荐运镜：**
- `aerial` - 航拍俯瞰沙丘和车辆
- `low-angle` - 低角度仰拍，展现车辆的霸气

**示例提示词：**
```
路虎卫士在撒哈拉沙漠中穿行，
无边的沙丘，烈日当空，车辆在沙漠中留下轨迹，
航拍俯瞰视角，展现苍茫的沙漠和车辆的探险精神。
```

---

### 5. 自然场景 (nature)

**地理特征：**
- 森林、草原、湖泊
- 国家公园、自然保护区
- 溪流、瀑布
- 四季景色

**视觉元素：**
- 绿色（森林、草原）
- 蓝色（湖泊、天空）
- 棕色（土地、树干）
- 四季色彩

**推荐风格：**
- `lifestyle` - 生活场景，展现家庭自然旅行
- `epic` - 史诗大片，展现自然奇观

**推荐运镜：**
- `tracking` - 平稳跟拍，展现车辆的舒适
- `wide` - 广角展现自然风光

**示例提示词：**
```
丰田汉兰达在黄石国家公园行驶，
森林、湖泊、野生动物，车辆在自然中穿行，
平稳跟拍镜头，展现车辆作为家庭伙伴的角色。
```

### 快速判断规则

**检测到以下关键词 → 对应场景：**

| 关键词 | 场景类型 |
|--------|---------|
| 海岸、海边、海滩、港口、海 | coastal |
| 山、山脉、高原、峡谷、阿尔卑斯 | mountain |
| 城市、街道、高速、都市 | urban |
| 沙漠、荒野、戈壁 | desert |
| 森林、草原、湖泊、国家公园 | nature |

## 地理API集成

### 地理信息获取

skill会自动调用地理API获取以下信息：

1. **地形信息**
   - 海拔高度
   - 地形类型（山地、平原、高原等）
   - 地貌特征

2. **气候信息**
   - 温度范围
   - 湿度
   - 光照条件（日照时间、日出日落时间）

3. **地标信息**
   - 附近的地标
   - 著名景点
   - 道路信息（道路类型、弯道、坡度）

### 地理信息融入提示词

示例：
```
原始提示词：特斯拉Model S在加州1号公路

地理API获取：
- 海拔：海平面
- 地形：海岸悬崖
- 气候：温暖、阳光充足
- 地标：大苏尔、圣塔芭芭拉

融入后的提示词：
特斯拉Model S沿着加州1号公路的海岸线行驶，
大苏尔的悬崖公路，阳光充足，
航拍俯瞰视角，展现壮丽的海岸线和太平洋背景。
```

# 拉片证据纪律：避免把分析模型的想象学成规则

本轮 54 个文件逐一送入完整视频理解，并用全时段每 3 秒抽帧交叉核对。抽帧会漏掉短于采样间隔的镜头、快速字幕和动作，不能据此宣称逐帧复核。自动切点只是候选：闪光、溶解、运动与亮度变化会误报，长镜头内的构图变化也可能漏报。需要精确剪辑点、对白逐字稿或拍摄复刻时，返回原视频对应区间再核查。

## 三层记录

1. **画面观察**：能在素材定位的场景、动作、物件、构图和状态。记录近似时间与来源文件指纹。
2. **编辑性解释**：为什么这一安排可能有效、人物关系可能如何理解。必须允许其他解释；“推论”不写成作者原意。
3. **原创制作建议**：可迁移的机制和参数建议。不是原片剧本、真实焦距、实际车速或拍摄设备。

模型辅助报告保留在本地研究目录，未原样纳入正式技能事实库。若报告与抽帧冲突，不能选更丰富的那个版本作为真相；先隔离、回看片段，仍不确定就保留不确定。

## 本轮实际发现的失真模式

| 模式 | 为什么不能沉淀 | 正确处理 |
| --- | --- | --- |
| 把两支拼接片解释成一个品牌的完整双线叙事 | 文件容器不等于作品边界，TVC07 中间已有独立落版 | 先分段再比较，不替作者制造呼应 |
| 把不同人物认作同一家人、不经证据指定民族或情侣身份 | 外形相似、同车或同景不证明关系 | 写可见人数和行为，身份待核实 |
| 给无冲突的生活/造型片补“都市焦虑—逃离—治愈” | 这是常见文案模板，不是画面事实 | 允许纯观察、形态揭示、感官变奏 |
| 把片内宣传参数、特效或动态画面叫“硬证据” | 不知道测试条件、后期与量产配置 | 用产品资料确认；成片只证明如何表达 |
| 自动生成精确口号、台词和音效 | 多模态模型可能补齐不存在的文字 | 无法辨认不引号引用，逐字稿另核声轨 |
| 断言实拍、手持、无人机、原焦距 | 成片效果常有多种制作方法 | 分“可见运动”与“复现方案” |
| 把 Z 轴当车辆前进方向 | 与 Blender Z-up 世界坐标矛盾 | 本工程明确局部 X 前、Y 左、Z 上 |
| 从一支片推出固定人车风景比例、固定镜数 | 样本方法被错误升级为通用法则 | 按信息与表演时间分配，只给当前方案建议 |
| 以“没有旁白”当去 AI 感准则 | 有优秀旁白片，也有空泛无旁白片 | 检查声画是否各增一层信息 |

## 新片例进入技能的最小记录

来源文件/链接与版本；可定位事件；核心机制；适用任务；不适用条件；原创转译；待核实项。不得把一次模型自评写成“用户认可”，不得给未知来源补官方、奖项或历史认证。重复素材的不同剪辑版本可分析节奏差异，但经验权重不简单翻倍。

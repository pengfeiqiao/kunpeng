# 九宫格三幕叙事分镜技能

基于三幕叙事结构的九宫格分镜生成规范。系统自动为每格分配景别、角度、镜头类型，用户只需提供核心叙事和风格参数。

---

### 第一幕 · 建立世界（格1-3）

## 二、全程一致性锚定（每个提示词开头必加）

```
【核心锁定】：{主角造型、服饰、面部特征}、{主要道具/车辆型号与颜色}、
整体色调、{胶片型号}、变形宽银幕镜头参数，全9格全程固定不变，
仅改变景别、拍摄角度、人物动作、环境背景。
```

实测：加入核心锁定指令后，系列画面一致性提升 85%，是九宫格生成最关键的一步。

## 三、执行流程

收到 `[电影大师·九宫格分镜]` 指令后：

### Step 1：解析参数
- 核心叙事（故事主线）
- 电影类型
- 角色/主体物理描述
- 胶片质感
- 画面比例
- 参考图（可选）

### Step 2：拆解九格脚本
根据核心叙事，按三幕九格框架拆解每格的具体内容：
- 主体在该格做什么（动作/状态）
- 所处什么环境
- 传递什么情绪
- 对应叙事功能

### Step 3：构建每格 BananaPro 提示词
每格提示词开头加全程核心锁定，然后按黄金公式（参见 SKILL.md）填写该格的专属参数，其中景别/角度/镜头严格按框架自动分配，不得由用户自行修改。

### Step 4：批量执行生图

```bash
# 每格依次执行；若接入鲲鹏工坊，生成动作需经过用户确认和质量检查
python ~/.openclaw/skills/film-master/main.py \
  --api-key "{bananaProApiKey}" \
  --prompt "{第N格完整提示词}" \
  --ratio "{画面比例}" \
  --count {每格张数} \
  --output-dir "{输出目录}/grid_{N}"
```

### Step 5：输出结果
- 输出完整9格提示词脚本（含格号、叙事说明、完整提示词）
- 告知每格图片保存路径
- 提供系列一致性迭代建议

## 四、通用负面指令（每格必加）

```
禁止出现：水印、logo、二维码、签名；
严格规避：畸形肢体、五官错位、比例失调、透视错误、穿模；
画面不得包含：过曝、死黑无细节、噪点过多、涂抹感；
所有画面符合现实世界物理光学规律，全9格画面风格、色调、主体造型保持高度一致。
```

## 五、迭代优化（系列一致性核心规则）

- **禁止整格重绘**：单次只改 1 个维度（如「保持画面其他所有内容完全不变，仅将构图从三分法改为对角线」）
- **跨格一致性修复**：若某格与其他格色调偏差，在该格提示词开头强化「核心锁定」指令，重新生成该格
- **分镜节奏调整**：若整体节奏偏快/偏慢，可在格3或格6处增加一个「过渡镜头」，用近景/中景补充情绪衔接

# 节奏诊断清单

## 场景级节奏
- [ ] 每个场景是否都推进情节或深化人物？
- [ ] 是否有连续 3+ 个场景节奏相同？（全是对话/全动作）
- [ ] 长场景和短场景是否交替？
- [ ] 场景长度是否与情感强度匹配？（高强度 = 短场景）
- [ ] 是否有场景可以合并或删除？

## 幕级节奏
- [ ] 第一幕是否太慢？（前 10 页有钩子吗？）
- [ ] 第二幕是否有"中间塌陷"？（50% 位置变慢）
- [ ] 第三幕是否太赶？（需要更多空间）

## 情节点节奏
- [ ] 情节点 I 是否在页 20-30？
- [ ] 中点转折是否在 50-55% 位置？
- [ ] 情节点 II 是否在页 75-90？
- [ ] 高潮是否在最后 15-20%？

## 戏剧弧线（大节奏）
- [ ] 情感强度是否递增？
- [ ] 是否有"呼吸时刻"？（高强度后的低强度场景）
- [ ] 紧张与释放的交替合理吗？
- [ ] "All Is Lost"时刻是否足够低？

## 节奏问题信号
- ⚠ 前 10 页没有钩子 → 太慢
- ⚠ 25-50% 之间没有明显的事件 → 第二幕塌陷
- ⚠ 连续 5+ 页全是对话 → 视觉节奏缺失
- ⚠ 高潮后还有 15+ 页 → 结尾太长
- ⚠ 开场 5 页就有高潮 → 进戏太快

# 对话禁忌 100 条 — 核心检查清单

## 1. 开场/问候（滥用率最高）
- [ ] "Hello, how are you?" 式无聊开场
- [ ] "How are you doing?" / "I'm fine" 无信息交换
- [ ] 天气开场白
- [ ] 电话开场寒暄

## 2. 借对话倒信息（As You Know, Bob）
- [ ] "As you know, Bob..." 式明显倒信息
- [ ] 角色告诉对方已经知道的信息
- [ ] "还记得吗..."、"你应该知道..."
- [ ] 通过对话向观众解释背景
- [ ] 两个角色互相告诉对方各自的职业/身份
- [ ] 角色对自己已知的事件做总结

## 3. 过度解释（On-the-Nose）
- [ ] 角色直接说出自己的情感（"我很生气"）
- [ ] 角色直接表达主题（"人应该勇敢"）
- [ ] 角色分析自己的心理状态
- [ ] 借角色之口解释隐喻/象征
- [ ] 角色总结故事的教训

## 4. 角色自言自语
- [ ] 独白式自言自语的动机不足
- [ ] 对空气说话解释剧情
- [ ] 对着镜子说话
- [ ] 大声思考（不走心的内心独白）

## 5. 统一风格的对话
- [ ] 所有角色语调、句式、词汇量相同
- [ ] 缺乏特色口头禅/方言/俚语
- [ ] 每句话都是完整的语法句子
- [ ] 对话中无人打断/叠话
- [ ] 情绪紧张时说话方式不变

## 6. 问答机械
- [ ] 一问一答不带情感
- [ ] 不答反问（Every question answered immediately）
- [ ] 对话中没有潜台词
- [ ] 角色总是诚实地回答问题

## 7. 角色自我描述
- [ ] "我是你哥哥"（观众已经知道）
- [ ] "我是个警察"（已经穿着警服）
- [ ] 角色在对话中描述自己正在做的事
- [ ] 角色描述自己的外貌

## 8. 不合时宜的幽默
- [ ] 危机时刻插入笑话
- [ ] 葬礼/悲剧场合的轻浮
- [ ] 幽默破坏了情感节奏

## 9. 重复与赘述
- [ ] 同样的信息被多次重复
- [ ] 角色复述刚才发生的事
- [ ] 电话中复述对方刚说的话

## 10. 过度说明（Over-Explaining）
- [ ] 动作/场景已经展示的内容再用对话解释
- [ ] 技术上不可能的详细解释
- [ ] 解释已经显而易见的动机

## 高效对话特征
- 每一句推进情节或深化人物
- 去掉角色名仍能分辨谁在说话
- 有潜台词（表面说A，实际传达B）
- 反映角色的教育背景、性格、情绪状态
- 有高低起伏的节奏

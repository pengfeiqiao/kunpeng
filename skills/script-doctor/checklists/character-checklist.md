# 角色深度 21 问

## 动机与目标
- [ ] 主角的核心欲望是什么？
- [ ] 主角的内在需求是什么（自己没意识到的）？
- [ ] 欲望 vs 需求之间是否有冲突？
- [ ] 反派的动机是否合理（反派不觉得自己是坏人）？
- [ ] 每个主要角色想要什么？

## 弧线与变化
- [ ] 主角在故事开始和结束时的状态是否不同？
- [ ] 变化是否有足够的铺垫？
- [ ] 关键转折点是否改变了主角？
- [ ] 配角是否也有弧线？（即使是小的）
- [ ] 导师角色是否有自己的旅程？

## 角色关系
- [ ] 主角 vs 反派的关系是个人化的吗（不只是正邪对立）？
- [ ] 盟友是否对主角构成挑战而非一味支持？
- [ ] 爱情故事（B故事）是否与核心主题相关？
- [ ] 是否有"角色配对"?（mirroring / foils）

## 背景与真实感
- [ ] 角色是否有一个"before story"（故事前的历史）？
- [ ] 角色的职业/身份是否被独特地运用？
- [ ] 角色是否有弱点？（不光是一个技能弱点，更是性格弱点）
- [ ] 角色是否有奇怪的小习惯/癖好？

## 语音与辨识度
- [ ] 去掉角色名后能否分辨对话是谁在说？
- [ ] 每个角色是否有自己的词汇范围？
- [ ] 角色在不同情绪下说话方式是否不同？
- [ ] 角色的教育/背景是否反映在语言中？

## 扁平角色警告标志
- 角色只在需要时才出现（plot device）
- 角色没有自己的观点/欲望
- 角色的动机是"推动情节"
- 角色之间可以互换而故事不变
- 角色的唯一功能是提供信息

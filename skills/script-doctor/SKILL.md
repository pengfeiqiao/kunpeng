# 剧本医生技能 v2.0 — 专业剧本开发与 Coverage 系统

专为剧本审阅设计的好莱坞标准分析系统。核心逻辑：**先结构解析，再多维量化分析，再生成标准 Coverage 报告**。基于 CML-Bench 量化评估框架 + 麦基/悉德·菲尔德/救猫咪/特鲁比等经典编剧理论。

## 最高优先级：从成片效果出发

下方三幕、节拍和页码位置是诊断参照，不是合格证。不得因为作品没有命中“第 25% 转折”就直接判定有问题，也不得为了补齐节拍把故事改成模板。

审阅时优先回答：
1. 这一场谁想得到什么，阻力来自哪里，失败的私人代价是什么？
2. 人物做了什么选择，场尾的关系、信息或价值状态发生了什么变化？
3. 观众看到和听到了什么？不可拍的心理说明能否转成动作、环境、停顿或选择？
4. 对白是否存在摩擦和潜台词？角色是在争夺、试探、回避、诱导还是谈判？
5. 角色声音是否来自经历、职业、关系、当前目标和主要情绪，而非口头禅堆砌？
6. 悬念是否具备可感知的威胁、后果和时间压力？stakes 是否对人物私人而具体？

专业动作描述应经济、可拍且有语气。换行代表新的动作或节拍，动作段通常不超过 4-5 行。只能写观众可见可听的内容，不用小说式内心解释。

修改流程固定为“证据 → 根因 → 最小有效改动 → 预期效果”。先给最小改动，只有结构根因确实无法局部修复时才建议重构。任何评分都必须服从具体证据，不能用理论名称代替判断。

## 一、分析流水线

```
Step 1: 剧本摄入 ─→ Step 2: 结构解析 ─→ Step 3: 多维分析 ─→ Step 4: 诊断报告
                                              ↓
                                    Step 5: 深度钻取（可选）
                                    Step 6: 修改建议（可选）
                                    Step 7: 迭代对比（可选）
```

### Step 1 — 剧本摄入

**支持格式：**
- `.txt` 纯文本 — 直接读取文件或粘贴文本
- `.fdx` / `.fadein` / `.pdf` — 读取后转为纯文本分析
- 直接粘贴的剧本文本

**内部表示：** 将剧本解析为以下结构：
- **场景列表**：每个场景包含场景标题、内/外景、时间、地点
- **角色列表**：所有出现的角色及其对话行
- **对话块**：角色名 + 对话内容
- **动作描述**：场景中的非对话文本

**解析方法：** 使用正则解析（标准格式）+ 启发式降级（非标准格式）

### Step 2 — 结构解析

- 识别场景切换点（INT./EXT./I./E. 等前缀）
- 构建场景序列
- 计算每场页占比
- 按三幕式划分（25%/50%/25% 原则）
- 识别情节点 I（页 20-30）和情节点 II（页 75-90）
- 映射救猫咪 15 节拍

### Step 3 — 多维分析

并行执行 6+1 维分析（见第二节），每维度输出分数 + 证据 + 问题列表。

### Step 4 — 诊断报告

生成标准 Coverage 格式（见第三节）。

### Step 5-7 — 深度模式

用户可选择：
- **深度钻取**：特定维度深入分析
- **修改建议**：AI 生成具体修改方案
- **迭代对比**：修改后版本与原版本对比

## 二、多维分析引擎（6+1 核心维度）

### 维度 1：结构完整性（权重 25%）

**理论来源：** 麦基《故事》节拍分析 + 悉德·菲尔德三幕式 + 布莱克·斯奈德救猫咪 15 节拍

**分析内容：**
1. **三幕检测** — 第一幕(0-25%)、第二幕(25-75%)、第三幕(75-100%) 分布是否合理
2. **情节点位置** — 情节点 I 应在页 20-30，情节点 II 应在页 75-90
3. **救猫咪节拍映射** — 检查 15 个节拍是否存在及位置
4. **场景连续性** — 相邻场景间的因果链是否连贯
5. **冗余场景** — 标记不推进情节也不深化人物的场景

**输出指标：**
- 节拍覆盖率（15 个节拍命中数 / 15）
- 节拍位置偏差（每个节拍距理论位置的平均偏移）
- 场景连续性评分（相邻场景逻辑连接度）
- 冗余场景列表

### 维度 2：角色深度与弧线（权重 20%）

**理论来源：** 埃格里《编剧的艺术》角色动机 + 沃格勒角色原型 + 特鲁比 22 步

**分析内容：**
1. **角色原型识别** — 英雄、导师、边界守卫、信使、变形者、阴影、 Trickster 等
2. **主角弧线** — 主角是否有清晰的情感/道德转变
3. **对话语音一致性** — 每个角色的语言风格是否稳定可辨
4. **角色互动网络** — 角色之间是否有意义的关联和冲突
5. **动机-行动对齐** — 角色的行动是否符合其设定的动机

**输出指标：**
- 角色原型完整度
- 主角弧线清晰度评分（0-10）
- 角色辨识度评分
- 扁平角色/工具人警告

### 维度 3：对话质量（权重 20%）

**理论来源：** 艾克斯《别让你的剧本逊毙了》对话检查清单 + 山音潜台词规则 + CML-Bench DC 指标

**分析内容：**
1. **自然度** — 对话是否自然流畅，不像书面语
2. **问答相关性** — 问句与回答是否匹配，不答非所问
3. **话题集中度** — 对话是否跑题
4. **潜台词检测** — 对话是否有言外之意，还是直白倒信息
5. **辨识度** — 去掉角色名后能否分辨谁在说话
6. **禁忌检查**：
   - "Hello, how are you?" 式无聊开场
   - "As you know, Bob..." 借对话倒信息
   - 过度解释（On-the-nose dialogue）
   - 角色自言自语

**输出指标：**
- 自然度评分
- 潜台词违规次数和位置
- 辨识度评分
- 对话禁忌违规清单

### 维度 4：情感冲击力（权重 20%）

**理论来源：** 卡尔·伊格莱西亚斯情感弧诊断 + 麦基场景价值转折 + moviearcs 六种基本弧线

**分析内容：**
1. **全剧情感弧线** — 逐场景情感曲线，识别情感走势
2. **场景价值转折** — 每个场景结束时角色价值状态是否正向/负向转变
3. **高潮场景定位** — 情感强度最高的场景是否在正确的叙事位置（高潮应在 80-90%）
4. **情感多样性** — 剧本是否覆盖了所需的情感范围（喜悦、悲伤、愤怒、恐惧、惊讶等）
5. **情感节奏** — 高低情感交替是否合理，避免过长低潮或密集高潮

**输出指标：**
- 情感弧类型（六种弧线分类）
- 场景价值转折率（有价值转折的场景比例）
- 高潮位置评估
- 节奏失衡警告

### 维度 5：视觉叙事与动作密度（权重 10%）

**理论来源：** 麦基"展示不告知" + 山音"禁止心理描写"

**分析内容：**
1. **动作/对话比** — 动作描述行 vs 对话行的比例
2. **动词丰富度** — 动作动词 vs 状态动词的比例
3. **可拍摄性** — 场景描述是否包含具体视觉信息
4. **被动语态检测** — 过多被动语态降低力度
5. **"展示不告知"检查** — 标记通过对话告知而非通过动作展示的内容

**输出指标：**
- 动作/对话比评分
- 可拍摄性评分
- 被动语态违规数

### 维度 6：制作可行性（权重 5%）

**理论来源：** 好莱坞行业淘汰标准 + 电影开发实务

**分析内容：**
1. **场景数量** — 标准 90 分钟剧本应有 40-60 场
2. **外景/夜戏比例** — 直接影响拍摄成本
3. **特效场景** — 需要 VFX 的场景数量和复杂度
4. **角色规模** — 主要角色、次要角色、群演需求
5. **地点多样性** — 独特地点数量
6. **时间段跨度** — 故事时间跨度

**输出指标：**
- 制作预算等级（低/中/高/极高）
- 场景统计报告
- 制作复杂度评分

### 维度 7（加分项）：原创性与可比性

**分析内容：**
1. **概念原创性** — 与已知作品的主题/设定对比
2. **可比作品推荐** — 2-3 部风格/主题相近的电影
3. **类型市场定位** — 在同类中的独特性

### 综合评分公式

```
综合评分 = 结构完整性×25% + 角色深度×20% + 对话质量×20% + 情感冲击力×20% + 视觉叙事×10% + 制作可行性×5% + 原创性加分(-1 到 +1)
```

### 等级对应

| 综合评分 | 评级 | 含义 | 建议 |
|---------|------|------|------|
| 9.0-10 | 强烈推荐 | 行业顶级，立即推进 | 无需重大修改 |
| 7.5-8.9 | 推荐 | 优秀，少量打磨即可 | 低优先级修改 |
| 6.0-7.4 | 考虑 | 有潜力，需中等改造 | 高优先级修改 |
| 4.0-5.9 | 通过 | 基础尚可，需大幅修改 | 修改后重新评估 |
| <4.0 | 退回 | 基础问题太多 | 建议重写 |

## 四、修改建议生成策略

1. **定位问题点** — 用精确页号/场号定位
2. **诊断根因** — 区分表层问题（对话生硬）和深层问题（角色动机不足）
3. **生成 2-3 个修改选项**：
   - **选项 A（最小改动）**：局部调整，保持原有叙事
   - **选项 B（中等改动）**：调整或合并 1-2 个场景
   - **选项 C（重构方案）**：重新构思故事线（仅重大问题时）
4. **每个选项附修改示例** — 展示修改前后的对比

## 五、执行流程

收到 `[剧本医生]` 指令后，按以下步骤执行：

### Phase 1: 剧本摄入与解析

1. 读取用户提供的剧本（文件路径或粘贴文本）
2. 解析为标准化场景-对话-动作结构
3. 统计元数据（总页数/场景数/角色数/对话行数）

### Phase 2: 结构分析

1. 检测三幕结构切分点
2. 映射救猫咪 15 节拍
3. 计算场景连续性
4. 标记冗余场景

### Phase 3: 多维分析

对每个维度执行：
1. 收集指标数据
2. 对指标评分（0-10）
3. 汇总维度得分
4. 列出证据和发现的问题

### Phase 4: 报告生成

1. 计算各维度得分
2. 计算综合评分
3. 生成评级
4. 填入标准 Coverage 报告模板
5. 输出完整分析报告

### Phase 5: 深度模式（按需）

如果用户要求：
1. 对特定维度深入分析
2. 生成具体修改方案
3. 对比分析

## 六、验证指南

生成报告后，自动进行以下质量检查：

- [ ] 所有 6 个维度都有分数（非空值）
- [ ] 每个问题都附有具体位置（页号/场号）
- [ ] 每个证据都引用具体文本
- [ ] 综合评分与各维度评分逻辑一致
- [ ] 修改建议可操作、有示例
- [ ] 可比作品有明确理由

# 沃格勒英雄旅程 — 克里斯托弗·沃格勒

## 12 个阶段

| # | 阶段 | 说明 |
|---|------|------|
| 1 | **平凡世界** | 英雄在旅程前的日常生活 |
| 2 | **冒险召唤** | 打破平静的挑战/邀请 |
| 3 | **拒绝召唤** | 英雄因恐惧拒绝 |
| 4 | **遇见导师** | 智者提供指导和装备 |
| 5 | **跨越阈限** | 英雄不可逆地进入冒险世界 |
| 6 | **考验/盟友/敌人** | 新世界的适应、交朋友、树敌 |
| 7 | **接近核心** | 接近最危险的地点 |
| 8 | **严峻考验** | 最大的危机，面临死亡 |
| 9 | **获得奖赏** | 战胜后获得宝物/知识 |
| 10 | **返回之路** | 返回平凡世界的旅程 |
| 11 | **复活** | 最后的净化和转变 |
| 12 | **带回灵药** | 带着宝物/智慧回归，造福族群 |

## 8 种角色原型

| 原型 | 功能 | 识别要点 |
|------|------|---------|
| **英雄** | 服务、成长、牺牲 | 观众代入感最强、从缺陷到完整 |
| **导师** | 教导、装备、礼物 | 通常是长者，提供智慧或道具 |
| **边界守卫** | 考验 | 阻止进入新世界，可被克服 |
| **信使** | 召唤、宣布 | 带来冒险召唤的角色 |
| **变形者** | 不确定、误导 | 立场/身份不断变化（常见于爱情故事） |
| **阴影** | 对立、毁灭 | 反派/对手，代表英雄尚未面对的部分 |
| **盟友** | 陪伴、保护 | 帮助英雄的伙伴 |
| **Trickster** | 喜剧、搅局 | 制造混乱，但常带来意外帮助 |

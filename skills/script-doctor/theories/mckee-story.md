# 麦基《故事》— 核心概念

## 场景价值转折

- 每个场景必须发生价值转折（正向或负向）
- 价值 = 角色的终极状态（生/死、爱/恨、真/假、正义/不义等）
- 无转折 = 非场景 = 冗余
- 价值变化必须 > 5% 才算有效转折

## 节拍分析

- **节拍（Beat）**：最小的叙事单位
- 场景由一系列节拍构成
- 节拍在角色间来回交换行动/反应

## 三幕结构

- 第一幕：设置（0-25%）— 引入主角、世界、冲突
- 第二幕：对抗（25-75%）— 困难递增，主角挣扎
- 第三幕：解决（75-100%）— 高潮 + 结局

## 激励事件（Inciting Incident）

- 打破主角平衡的事件
- 发生在第一幕，通常在 10-15% 位置
- 必须让主角不可逆转地投入旅程

## 故事价值

1. **生存/死亡** — 最基础的生理价值
2. **正义/不义** — 社会价值
3. **自由/奴役** — 政治价值
4. **爱/恨** — 情感价值
5. **真相/谎言** — 认知价值
6. **勇气/懦弱** — 道德价值

## 冲突层级

1. **内心冲突** — 角色与自己
2. **人际冲突** — 角色与角色
3. **外部冲突** — 角色与社会/自然/超自然

## 高潮原则

- 高潮必须在最后（80-90% 位置）
- 高潮必须是 irreversible 的
- 高潮让观众获得情感满足，而非智力满足

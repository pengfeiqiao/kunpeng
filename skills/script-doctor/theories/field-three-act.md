# 悉德·菲尔德三幕式结构

## 三幕式范式

```
第一幕 (Setup)     第二幕 (Confrontation)     第三幕 (Resolution)
 0%──25%─────────────25%──75%─────────────────75%──100%
     │                      │
   Plot Point I          Plot Point II
   (20-30页)             (75-90页)
```

## 第一幕：设置（页 1-25）

**内容：**
- 引入主要角色
- 建立故事世界
- 揭示主角的内在需求
- 设置冲突的前提
- **情节点 I（Plot Point I）**：发生在页 20-30，角色做出不可逆的决定，故事真正开始

## 第二幕：对抗（页 25-80）

**内容：**
- 主角面临越来越大的障碍
- 次级情节复杂化
- 中点转折（Midpoint）：故事方向改变
- 主角最低点（All Is Lost moment）
- **情节点 II（Plot Point II）**：发生在页 75-90，推动故事进入第三幕

## 第三幕：解决（页 80-110）

**内容：**
- 最后的冲突升级
- 高潮
- 结局/解决

## 检查清单

- [ ] 情节点 I 是否在页 20-30 之间？
- [ ] 情节点 II 是否在页 75-90 之间？
- [ ] 第一幕是否建立了冲突前提？
- [ ] 第二幕障碍是否递增？
- [ ] 第三幕高潮是否令人满意？
- [ ] 故事结尾是否解决了核心冲突？

# 锚定图记录模板

复用项目现有文案，按版本追加，保留旧记录。未知项不填“通过”。

| 字段 | 记录 |
| --- | --- |
| 对象 / 环境组 | 地点、时间、天气、主要光源 |
| 版本 / 文件 | 现有版本号、真实产物路径 |
| 参考顺序 | @图片1=路径+职责，依序列全 |
| 修改 / 保留 | 本轮目标与禁止变化 |
| 身份 / 结构 / 光照 | 各项通过、失败或未知，附证据 |
| 局部核验 | 原图像素区域、证据路径、主观确定程度及理由 |
| 像素差分 | 对比路径、阈值、区域外变化数；未执行写未执行 |
| 空间 / 连续性 | 左右定义、进出方向、道具状态与邻镜关系 |
| 结论 | 候选、用户认可、否决；用户认可须有明确依据 |
| 否决理由 / 允许偏差 | 不覆盖旧版，不擅自接受偏差 |

# 鲲鹏视频分析记录

复用现有参考片档案，不要求用户填表，不强制为简单问答创建文件。

- shotTable：源片时间段、可见动作、景别/构图、镜头变化和视听证据。
- visualDesign：从画面可确认的层级、位置、色彩关系与贯穿规则；估计值注明近似。
- htmlCssPatterns：只在确有图形或界面时描述其行为，不猜原作者使用的代码或软件。
- semanticEvents：源片时间范围、触发词句或动作、响应元素、进入/保持/退出、跨镜头是否持续。未逐词对齐时不填虚构精确时间。
- recreationPlan：用户目标下的保留/替换/待定项，以及哪些变化会影响其他元素。无目标时只列可借鉴关系，不擅自确定新人物、新台词或生成预算。
- evidenceLimits：未覆盖片段、听不清的词、抽帧无法确认的运动、需要进一步查看的时间范围。

例如：“约 4–6 秒，口播给出对比结论时右侧条形图增长；作用是把差异视觉化。换主题后保留结论触发增长的关系，替换数值和文字；新时刻须按新口播确定。”这是记录形式示例，不是对用户视频的观察。

这些字段是创作证据和交接信息，不是质量认证、自动审片分数或新的制作合同。缺少某一类元素就不强行补齐。

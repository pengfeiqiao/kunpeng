# 场景图生成工作流 — 环境锚定法

## 第一步：场景分组

将所有镜头按 **环境类型** 分组。同一环境 = 同一空间/场景的多个角度或时间点。

| 判断维度 | 说明 | 示例 |
|---|---|---|
| 空间一致性 | 是否在同一个物理空间内？ | 航天器对接舱内部（镜3+镜4） |
| 色调一致性 | 是否共享同一色调方案？ | 外滩暖黄金色（镜9+镜10+镜11） |
| 光影一致性 | 是否共享同一光源设置？ | 暗黑虚空冷白光（镜1+镜2+镜5+镜6） |

**规则**：只要有两个及以上维度一致，就归为同一组。

## 第二步：串行/并行判断

```
同组 = 串行（用锚定图保持一致性）
不同组 = 并行（互不影响，可同时跑）
```

| 关系 | 条件 | 原因 |
|---|---|---|
| **并行** | 不同环境类型 | 航天器内部 vs 上海外滩，视觉无关联 |
| **并行** | 同组的不同细节变体 | 基于同一锚定图生成的多个角度，互不依赖 |
| **串行** | 同组且后者依赖前者的空间设定 | 镜3建立航天器内部 → 镜4在同一空间内变体 |

## 第三步：Phase 1 — 锚定图生成（全部并行）

每组生成1张锚定图，使用 **text-to-image**（纯提示词，无参考图）。

```
每组一条命令，全部并行启动：
├── 场景A锚定图  ← text-to-image
├── 场景B锚定图  ← text-to-image
└── 场景C锚定图  ← text-to-image
```

锚定图是全组的视觉基准，必须完整描述该环境的所有视觉要素。

## 第四步：Phase 2 — 变体图生成（组间并行）

用 Phase 1 的锚定图作为参考，使用 **image-to-image** 生成变体。同锚定的多个变体之间也可以并行。

```
全部并行启动：
├── 场景A变体1 ← image-to-image, ref: 锚定A
├── 场景A变体2 ← image-to-image, ref: 锚定A
├── 场景B变体1 ← image-to-image, ref: 锚定B
└── 场景C变体1 ← image-to-image, ref: 锚定C
```

变体图提示词聚焦于该镜头的独特要素（角度、焦点、细节），通过 `--image` 传入锚定图确保视觉一致性。

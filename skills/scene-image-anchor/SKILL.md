# 分镜生图一致性规则

本规则自动用于工坊、画布和普通对话中的分镜生图，不作为用户可选择的技能显示。

## 先判断已有参考

1. 已有用户认可的构图参考：仅承担构图、景别和人物关系；不强制创建分镜板，不重排已有参考数组。
2. 有场景资产：场景资产是环境锚点，优先保持空间结构、材质、光源方向和时间天气。
3. 没有场景资产：同一环境第一次生成的合格画面成为锚点，后续同环境镜头以它做图生图变体。
4. 只有一镜时仍检查角色、场景、道具和色卡引用，不强制额外生成锚点图。

## 多镜一致性

- 按地点、时间、天气和主要光源分组。同组共享锚点，不同环境不能强行共用。
- 变体允许改变机位、景别、人物动作和局部陈设，不改变房间拓扑、地貌结构、门窗位置、关键材质和主光方向。
- 人物身份与服装来自工坊角色资产模板；道具状态必须承接前后镜头。
- 色卡只在完整提示词末尾统一引用一次，不在每个短句重复色调。
- `@图片N` 必须来自当前真实 reference order。不得猜编号，不得把色卡、角色图或已生成视频误写成场景锚点。

## 生成策略

- 单镜可单独生成，不要求八张或整组。
- 多镜确认后可并行生成；同一环境先确认锚点成功，再并行生成变体。
- 重生成、任务列表重试和画布传递必须保留原参考图数组、顺序、模型、比例和分辨率。
- 使用当前界面选择的生图模型；本规则不绑定供应商。

## 锚定图与局部修改

- 锚定图、定调图、局部修改和跨镜一致性任务按需调用 `skill_invoke(anchor-frame-production)`。身份、结构、环境、色彩分别指定参考职责。
- 只改提示词不触发生成。车型、驾驶位与时长按项目事实确定，不沿用案例。
- 用 `image_inspect` 裁切细节或对同尺寸图做像素差分；看不清记未知，不能顺着问题猜结论。
- 沿用候选、版本和采纳入口，在项目文案记录证据、否决理由、允许偏差及连续性。生成成功不代表用户定版。
- 提交状态未知时查 `task_status` 与逐项回执，不自动重提或换渠道。

## 汽车驾驶安全带（强制）

汽车驾驶画面强制规则：凡画面涉及人物驾驶汽车，最终图片或视频提示词必须明确写出“驾驶者全程正确系好安全带，肩带斜跨胸前、腰带贴合髋部并扣紧”；不得仅写在分析或负面提示中。换机位、局部修改、风格改写和连续镜头均须保留此约束，不得出现安全带消失、解开、穿模或置于背后。近景可见部位必须正确呈现；遮挡时保持佩戴事实，不为展示安全带擅自改变构图。纯车辆空镜不新增人物。
核验驾驶人物时检查安全带；明确缺失或佩戴错误的候选不得判为合格，遮挡看不清须标记未确认。

# 现代旅游风光影视片风格

## 风格简介

现代旅游风光影视片风格是一种以自然景观为核心、强调光影诗意和旅行探索的电影级视觉风格。

### 核心特征

- **画幅**: 16:9 标准宽屏
- **人物占比**: 5-15%（极小），强调环境
- **构图**: 三分法60%、对称20%、留白20%
- **色彩**: 暖色调为主(70%)，中高饱和度(0.6-0.8)
- **光影**: 自然光(85%)，黄金时刻(50%)，逆光/侧逆光(50%)
- **场景**: 自然风光60%、人文景观30%、城市建筑10%
- **氛围**: 宁静诗意40%、探索冒险30%、温暖治愈20%

### 特殊功能

- **真人参考图**: 支持用户提供真人照片作为人脸参考，生成更真实的人物形象

## 使用方法

### 触发方式

在对话中输入以下任一关键词即可触发：
- "现代旅游"

- "旅游影视片"
- "现代风光"
- "旅游纪录片"
- "风光影视片"
- 或输入 "3"（第三个风格选项）

#### 1. 项目创建
```

```

      如果没有，请输入'无'，系统将按照描述生成角色。

用户: C:/Photos/my_face.jpg  # 或 "无"

系统: 请提供角色信息
      姓名、年龄、性格、服装

系统: 生成定妆照（1-2张）

**注意**:
- 如果提供真人照片：系统会保持真人脸部特征，仅改变服装和场景
- 如果不提供：按正常流程生成角色

#### 3. 场景创建
```
系统: 请描述场景
      场景名称、环境描述、光影时段、人物

系统: 生成场景概念图（16:9，人物占比5-10%）
```

#### 4. 分镜生成
```
系统: 生成九宫格分镜
      - 画幅：16:9
      - 人物占比：5-15%
      - 强调横向构图和空间感
```

## 光影时段

### 黄金时刻 (50%)
- **时段**: 日出后1小时/日落前1小时
- **色温**: 3200K
- **特点**: 暖色调、柔和阴影、金色轮廓光
- **氛围**: 宁静诗意

### 白天 (35%)
- **时段**: 白天（多云或晴天）
- **色温**: 5600K
- **特点**: 均匀照明、色彩饱和、细节清晰
- **氛围**: 明亮清新

### 蓝调时刻 (10%)
- **时段**: 日出前/日落后30分钟
- **色温**: 4500K
- **特点**: 蓝色天空、柔和阴影、低对比度
- **氛围**: 静谧温柔

### 阴天 (5%)
- **时段**: 阴天
- **色温**: 6500K
- **特点**: 柔和漫射光、均匀照明、戏剧性云层
- **氛围**: 沉静内敛

## 角色模板

### 旅行者（男）
- **年龄**: 20-40岁
- **性格**: 自由、探索、沉静、热爱自然
- **服装**:
  - 春夏：轻薄冲锋衣（浅灰/卡其），速干裤，登山鞋，遮阳帽，登山包
  - 秋冬：保暖冲锋衣（深蓝/黑色），抓绒内胆，户外裤，登山鞋，保暖帽，登山包
- **配件**: 登山包（40-60L）、遮阳帽/保暖帽、太阳镜、手表、水壶

### 旅行者（女）
- **年龄**: 20-35岁
- **性格**: 独立、勇敢、温柔、好奇
- **服装**:
  - 春夏：轻薄防晒衣（白色/浅蓝），长裙（民族风/纯色），登山鞋，草帽
  - 秋冬：保暖冲锋衣（深红/深蓝），抓绒内胆，户外裤，登山鞋，围巾
- **配件**: 相机包、草帽/毛线帽、围巾、墨镜

### 摄影师
- **年龄**: 25-45岁
- **性格**: 专注、艺术、寻找、敬畏自然
- **服装**: 工装背心，摄影包，三脚架
- **配件**: 单反相机/微单相机、多个镜头、滤镜、三脚架、摄影包

## 真人参考图功能

### 功能说明
- 系统会在人物创建时询问是否有真人参考照片
- 如果提供真人照片：系统会保持真人脸部特征，仅改变服装和场景
- 如果不提供：按正常流程生成角色

### 使用方法
```
系统: 是否有真人参考照片？
用户: C:/Users/<用户名>/Desktop/my_face.jpg
系统: 已收到真人参考照片，接下来请提供角色信息。
```

### 技术实现
- 使用 Gemini API 的图像编辑能力
- 保持真人脸部特征（相似度60-80%）
- 无需额外依赖，使用现有的 Gemini API 客户端

### 优势
- 无需安装额外软件
- 跨平台兼容
- 实现简单，易于维护

### 限制
- 融合效果相似度60-80%（不如专业工具）
- 需要API调用费用
- 处理时间10-30秒

## 构图规则

### 人物占比
- **超大远景**: 人物<5%，展现宏大场景
- **远景**: 人物5-10%，展现环境全貌
- **中远景**: 人物10-15%，平衡环境与人物

### 人物朝向
- **背影**: 50% - 眺望远方，强调探索感
- **侧影**: 30% - 轮廓剪影，增强艺术感
- **正脸**: 20% - 情感表达，传递共鸣

### 构图方式
- **三分法**: 60% - 人物位于交点或线条上，营造平衡感
- **对称**: 20% - 适用于建筑、桥梁，营造庄严感
- **留白**: 20% - 大面积天空或水面，强调空间感和诗意

## 色彩特征

### 主色调
- **金色**: 阳光、建筑、秋季植被
- **森林绿**: 森林、草地、植物
- **天蓝**: 天空、水面
- **日落橙**: 日落、人工灯光

### 辅助色
- **大地棕**: 大地、岩石、木质
- **雾白**: 云朵、雾气、雪
- **山灰**: 山脉、阴天、石质

### 色彩参数
- **饱和度**: 0.6-0.8（中高）
- **明度**: 0.5-0.7（中间调）
- **对比度**: 0.6-0.75（中高）

## 氛围基调

### 宁静诗意 (40%)
- **关键词**: serene, peaceful, poetic, tranquil, meditative
- **特点**: 慢节奏旅行，内心平静与自然和谐

### 探索冒险 (30%)
- **关键词**: adventurous, exploration, freedom, journey, discovery
- **特点**: 旅行的动感与激情，未知的前方

### 温暖治愈 (20%)
- **关键词**: healing, warm, belonging, comfort, emotional
- **特点**: 情感共鸣，寻找自我

### 壮阔史诗 (10%)
- **关键词**: epic, breathtaking, majestic, grand, awe-inspiring
- **特点**: 自然的磅礴气势，震撼人心

## 质量标准

### 视觉风格
- Cinematic landscape photography
- 16:9 aspect ratio, standard widescreen
- Natural lighting, NOT studio lighting
- Cinematic color grading, film-like quality
- Travel documentary style
- Landscape as main subject
- Shallow depth of field for figures, deep focus for landscape
- High resolution, sharp details
- Rich textures and vibrant colors
- Film grain for cinematic feel

### 负向提示
- 过度饱和
- 塑料质感
- 人工光源
- 摆拍感
- 人物占比过大
- 杂乱背景
- 现代物品穿帮（如塑料袋、广告牌）

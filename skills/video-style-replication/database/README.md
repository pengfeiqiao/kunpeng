## 📚 文档说明

### 1. workflow_analysis.md
**完整流程回顾**
- 记录了8个版本的迭代过程
- 分析了每个版本的成功与失败
- 总结了关键经验与教训
- 提炼了核心方法论

**关键经验**：
1. 保留写实基础（v3的写实约束是核心）
2. 精准控制增强（不是越多越好）
3. 明确安全边界（标注禁止调整项）
4. 混合策略（v3人脸美化 + 视频级光影）
5. 禁止美化优化（1:1还原比美化更接近视频）

### 2. skill_optimization_plan.md
**Skill优化方案**
- 设计了纯分析工具（无需预设风格）
- 实现了风格隔离机制（独立命名空间）
- 标注了安全边界（避免CG化）
- 提供了精准控制方案（百分比控制）

**核心原则**：
1. 纯分析工具：不预设风格，自动分析视频
2. 风格隔离：每个风格独立命名空间，互不污染
3. 安全边界：明确标注禁止调整项，避免CG化
4. 精准控制：百分比控制增强强度
5. 可复用：保存到数据库，随时调用

### 3. awakening_prompt_no_text.md
**无文字版提示词模板**
- 基于混合版的最佳实践
- 明确禁止图片中出现任何文字
- 包含完整的视觉系统参数
- 可直接用于生成新图片

## 🚀 使用方法

### 调用已保存的风格
```bash
# 使用"未来废土风"生成新图片（参考图路径通过参数传入）
python3 scripts/generate_awakening_no_text.py <参考图路径>
```

### 创建新风格
```bash
# 分析新视频
python3 scripts/analyze_style.py --url "视频链接" --name "新风格名"
```

### 查看所有风格
```bash
# 列出数据库中的所有风格
python3 scripts/list_styles.py
```

- 每个风格有唯一ID
- 风格之间完全独立，互不污染

# 视频复刻 Skill 优化方案

## 一、设计原则

### 1.1 核心定位
**视频复刻 Skill 是一个纯分析工具，不是预设风格生成器**

- ✅ 分析视频风格（自动提取）
- ✅ 对齐风格（迭代调整）
- ✅ 保存风格（数据库存储）
- ✅ 独立调用（风格隔离）
- ❌ 不预设风格（用户无需提供风格名）

### 1.2 工作流程
```
用户提供视频 → 自动分析风格 → 生成初版 → 用户反馈 → 对比分析 → 调整策略 → 再次生成
     ↓                                                              ↓
保存到数据库 ← 风格对齐 ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ←
```

class StyleIsolation:
    """确保风格之间完全隔离"""

    def __init__(self):
        self.styles = {}  # 风格字典
        self.active_style = None  # 当前激活的风格

    def create_style(self, style_name, style_profile):
        """创建新风格（独立命名空间）"""
        style_id = f"style_{datetime.now().strftime('%Y%m%d')}_{style_name}"

        # 检查命名冲突
        if style_id in self.styles:
            raise ValueError(f"风格 {style_name} 已存在")

        # 创建独立命名空间
        self.styles[style_id] = {
            "profile": style_profile,
            "history": [],
            "metadata": {}
        }

        return style_id

        """加载风格（确保隔离）"""

### 4.2 安全边界标注
```python
class SafetyBoundary:
    """标注安全边界，避免CG化"""

    SAFE_ADJUSTMENTS = {
        "自然随机光斑": {"range": (10, 20), "default": 15},
        "暗部透气度": {"range": (5, 15), "default": 10},
        "实拍颗粒感": {"range": (5, 12), "default": 8}
    }

    CAUTIOUS_ADJUSTMENTS = {
        "运动模糊": {"max": 10, "warning": "过高会导致画面发虚"},
        "冷暖渐变": {"max": 5, "warning": "过高会导致色彩失真"},
        "高光偏移": {"max": 8, "warning": "过高会导致材质塑料感"}
    }

    FORBIDDEN_ADJUSTMENTS = [
        "强行修改透视比例",
        "拉高饱和度、对比度",
        "过度磨皮/锐化材质",
        "美化式光影优化"
    ]

    def validate_adjustment(self, adjustment_name, value):
        """验证调整是否安全"""
        if adjustment_name in self.FORBIDDEN_ADJUSTMENTS:
            return False, "禁止调整"

        if adjustment_name in self.CAUTIOUS_ADJUSTMENTS:
            max_value = self.CAUTIOUS_ADJUSTMENTS[adjustment_name]["max"]
            if value > max_value:
                return False, f"超过最大值{max_value}%"

        return True, "安全"
```

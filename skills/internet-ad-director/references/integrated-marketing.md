# 整合营销 / 联名 / 情绪雷达 打法库

> 用途：给互联网广告导演/创意总监做全渠道整合营销提案时的方法论与案例底座。第一节是「整合营销矩阵」（七类可落地打法），第二节是「联名跨界创意引擎」（怎么选联名对象 + 范式案例），第三节是「时代情绪雷达」（怎么捕捉时代情绪做共鸣，分区域）。每类打法 = 方法论要点 + 带数据的代表案例 + 可复用模板。

---

## 第一节 · 整合营销矩阵

整合营销的核心逻辑：**单一创意 → 多触点放大 → UGC 接力 → 闭环转化**。任何接触点都是广告。下面七类打法按"线下→线上→公关→共创"排列，可单用，也可组合成 campaign。

### 1.1 线下装置 / 事件营销

**方法论要点**
- 三大放大器：① **奇观化**（巨型化、地标占位、极端视觉冲突）② **高成图率**（天然适合拍照/打卡的构图与配色）③ **场景反差**（日常空间被意外改造制造惊喜）。
- 装置必须自带传播钩子：要么是符号化记忆点（品牌色/IP/产品拟物），要么是社会议题载体（环保/治愈/在地文化）。
- 进阶：把装置变成**互动入口**（扫码、AR、参与机制），打通"打卡 → 转化"闭环。

**代表案例（含数据）**
- **LV 阿那亚沙滩巨型装置（2022 中国）**：黄金海岸搭巨型沙质城堡/人像装置，"放大的游乐场"。小红书/抖音/微博 UGC 数万条，现象级奢侈品事件营销。奇观化 + 高成图率 + 稀缺感反差。
- **美的旧空调巨型二维码墙（2022 中国）**：用回收旧空调在广州沙湾搭巨型二维码，路人扫码参与以旧换新。装置即互动入口，环保议题 + 转化闭环。
- **闲鱼"大地广告牌"沙塑装置（2023 中国）**：双 11 期间打造"被沙漠入侵的城市"，slogan"让草长在该长的地方"与装置深度融合，引发"断舍离"讨论。
- **ubras 公交站台穿肌底衣（2022 中国）**：入冬给站台座椅/扶手"穿上"肌底衣材质，产品功能（触感）可视化，"被 ubras 暖到了"刷屏。
- **网易云音乐"海上生明月"乐评投影（2022 中国）**：象山景区以海天为背景投影用户乐评，东方美学 + 用户参与感（自己的乐评被投影），延续乐评 IP 资产。
- **奢侈品秀场即媒体**：BV 长城新春 LED（品牌色点亮地标）、LOEWE 巨型红掌花、DIESEL 吉尼斯纪录充气人偶、Saint Laurent × Es Devlin 沙漠发光绿洲——共性是"秀场装置 = 当季最强视觉记忆锚点"。

**可复用模板**
```
装置事件 = [品牌符号/产品/IP] 的 [巨型化/拟物化/地标占位]
         + 落点选择（高人流 or 强地标 or 节点借势）
         + 传播钩子（成图率高的构图 + 一句可转述的 slogan）
         + （可选）互动入口（扫码/AR/参与机制）→ 转化闭环
```

### 1.2 H5 裂变 / 小程序刷屏

**方法论要点**
- 裂变引擎 = **个性化生成 + 社交货币 + 一键分享**。
- 四大驱动力：① "这就是我"的身份认同（个人数据可视化）② 稀缺/独一无二感 ③ 好奇心/争议性（准不准）④ 朋友圈展示/攀比心理。
- 必备：低门槛参与 + 结果卡片强分享设计 + 节点借势（年度/节日/赛事）。

**代表案例（含数据）**
- **网易云音乐年度听歌报告（2021-2024 每年迭代）**：用全年听歌数据生成"年度人格"标签，多屏长图 + 动效 + 煽情文案。单年分享量数千万级，微信生态最稳定的年度刷屏 H5。
- **全民数字雪花（2022-2025）**：小程序生成专属"数字雪花"，每朵独一无二，借势冬奥/冬季节点。生成 3 亿朵，UGC 超 2000 万条。
- **网易云"你的性格主导色"测试 H5（2021）**：听歌偏好测人格色彩卡片（"金色——你是落日弥漫的橘"）。上线当天朋友圈刷屏，#性格主导色# 登微博热搜。
- **腾讯 Next Idea × 故宫"朱棣穿越"H5（2021）**：让明朝皇帝戴墨镜唱 Rap 发朋友圈，反差 + 故宫 IP 国民度。上线数小时刷屏，话题阅读量破亿。
- **京东"AR 炸年兽"（2021）**：AR 扫一扫炸年兽领年货券，年兽 IP + 红包刺激。参与量超千万（技术方：网易易现 EZXR）。
- **腾讯公益"小朋友画廊"一元购画**：1 元购自闭症儿童画作电子版，零成本参与 + 强情感共鸣。累计参与超 2000 万人次、筹款超 1500 万（首爆 2017，2021-2025 持续被复刻）。

**可复用模板**
```
裂变 H5 = [用户个人数据/偏好] → 个性化生成 [人格标签/专属物/测试结果]
        + 社交货币包装（唯美文案 + 卡片化结果）
        + 一键分享 CTA + 节点借势
        + （进阶）利益钩子（红包/优惠券）或公益钩子放大转发
```

### 1.3 互动广告 / AR·VR 体验

**方法论要点**
- 把"看广告"变成"玩广告"：游戏化任务 + 集卡/集成就机制驱动裂变。
- O2O 设计：包装/货架/门店即入口（扫码/AR 触发），打通门店动线 → 小程序 → 会员 → 社交分享全链路。
- 内容要适合短视频二次创作（AR 滤镜、特效）。

**代表案例（含数据）**
- **LOEWE × Suna Fujita AR 寻宝 + 滤镜（2023 全球）**：门店内 AR 寻宝集 6 个联名角色，集齐解锁限量福利，配 6 款 AR 滤镜。打通门店 + 小程序 + 会员 + 分享全链路（技术方：Kivicube）。
- **Babycare × EZXR 山海经 AR 游戏（2022）**：山海经世界观 AR 任务领双 11 福利，国潮 IP + 沉浸感，参与量数百万。
- **伊利"新年 AR 雪花"（2022）**：扫产品包装触发 AR 雪花 + 互动游戏，包装即入口。扫描量数千万，#伊利下雪了# 上热搜。
- **世纪联华 AR 商超游戏（2022）**：超市货架变游戏关卡，AR 扫描显示优惠，试点门店客单价与滞留时间显著提升。

**可复用模板**
```
互动广告 = [IP/世界观] + 游戏化任务（集卡/闯关/AR 寻宝）
         + 入口设计（包装/货架/门店扫码触发）
         + 利益解锁（限量福利/优惠券）
         + 可二创素材（AR 滤镜/特效）→ 短视频接力
```

### 1.4 PR Stunt / 公关事件

**方法论要点**
- 制造**信息错位/反常识**：大品牌自爆短板、反食欲视觉、自残式产品体验——用"意外"换话题。
- 把抽象主张做成可感知的"表演":道歉做成广告、产品发霉证明无防腐剂、打扁汉堡引出校园霸凌。
- 公益/社会议题背书可降低激进创意的争议风险。

**代表案例（含数据）**
- **Burger King "Reclaim the Flame"公开认错（2024-2025 美国）**：奥斯卡直播 90 秒广告，CEO 出镜点名自身问题（旧门店/慢/品质不稳），把"道歉"做成表演化公关，与门店翻新长期绑定。
- **BK "Moldy Whopper"发霉皇堡（2020-2021）**：拍 Whopper 34 天发霉全过程，反食欲视觉反证"无人工防腐剂"，获戛纳 PR 类金奖（David Miami / We Believers）。
- **BK Whopper 耳虫洗脑歌（2022-2023）**：重复"Whopper, Whopper…"魔性歌词，被 TikTok 大量二创当 BGM，广告本身成 meme。
- **IKEA "城市里的家"快闪系列（2021-2024 多国）**：把地铁站/商场中庭改造成宜家家居空间，"城市即客厅"，可全球标准化复制。
- **肯德基"可达鸭"盲盒疯抢（2022 中国）**：宝可梦联名儿童餐赠品，可达鸭呆萌 + 随乐摆动引爆。话题阅读量数十亿，二手炒至数百元，"今天你得到可达鸭了吗"成国民话题。

**可复用模板**
```
PR Stunt = 反常识 hook（自爆/反食欲/自残式体验/意外改造）
         + 一个可被媒体一句话转述的"事件"
         + （可选）社会议题/公益背书降风险
         + 长期品牌动作绑定（翻新/产品力/价值观）
```

### 1.5 UGC 挑战赛 / 抖音 TikTok 裂变

**方法论要点**
- 强记忆符号 = **音乐 + 动作 + 品牌名强绑定**，门槛要低到"谁都能跟"。
- 算法正循环："用户创作 → 算法推荐优质内容 → 二次传播"。
- 利益激励（优惠券/免单/福利）+ 线下核销 = O2O 闭环。

**代表案例（含数据）**
- **统一老坛酸菜"酸爽摇摆舞"抖音挑战（2023）**：定制洗脑音乐 + 标志动作。单日 87 万条模仿视频，音乐使用量破 1.2 亿次。
- **蜜雪冰城主题曲（2021）**：改编《Oh! Susanna》，歌词只有一句、魔性旋律 + 歌词与品牌名强绑定。B 站官方 MV 播放破 2000 万，话题播放超 100 亿次，全民二创（方言/变装版本）。核心创意方：**华与华**（品牌策略 + 歌曲创意）。
- **Chipotle #GuacDance（TikTok）**：借 National Avocado Day 发起牛油果舞，跳舞领免费牛油果酱。话题播放超 10 亿次（当时 TikTok 品牌挑战赛纪录），当天牛油果酱订单增长超 100%。
- **伊利"牛奶盒创意改造"挑战（2023）**：用奶盒二次创作上传抖音，环保主题 + 创意贴纸辅助，超 200 万用户参与，话题播放数亿。
- **华为"镜头下的团圆时刻"（2023）**：春节用华为手机拍团圆影像，不强推产品。上传 4.3 万条家庭影像，37% 主动加品牌文案。
- **抖音本地生活挑战赛矩阵（2023-2025）**："挑战 99 元吃垮 XX 店"达人探店 + 优惠驱动，已成本地生活标准打法。

**可复用模板**
```
UGC 挑战 = 强记忆符号（神曲/标志动作/创意贴纸）
         + 极低门槛（一句歌词/一个动作）
         + 利益激励（免单/优惠券/福利）+ 节点借势
         + 算法推荐放大优质 UGC → （可选）线下核销闭环
```

### 1.6 用户共创 / UGC 社区

**方法论要点**
- 把消费者变创作者：投票/众创机制本身就是传播；用户作品自带粉丝基础。
- 长期社区运营 + 定期爆款转化，把单次活动沉淀成品牌资产。
- "宝藏品牌被网友主动发现"的自然叙事，比品牌自夸更可信。

**代表案例（含数据）**
- **LEGO Ideas 创意平台（持续运营 全球）**：用户提交创意、投票优秀者量产（如《老友记》中央公园套装）。累计提交超百万件，每个量产案例都成社区传播事件。
- **鸿星尔克"野性消费"（2021 中国）**：河南水灾低调捐 5000 万，"快倒闭还捐这么多"引发心疼式消费。微博热搜连霸多天，单日直播破亿，线上线下断货，"野性消费"成年度热词（纯自然传播，无代理商）。

**可复用模板**
```
用户共创 = 共创/投票机制（提交→投票→量产）
         + 创作者身份转变 + 作品自带粉丝
         + 长期社区运营 + 定期爆款
         + （自然型）品牌真实善举 → 网友主动发现叙事
```

### 1.7 CEO / 个人 IP 营销

**方法论要点**
- CEO 即品牌第一媒体：发布会/社交账号本身就是内容事件。
- 个人 IP 靠长期叙事积累（"最后一次创业""真还传""零广告"），争议性自带流量。
- 全平台矩阵分发（微博/抖音/B 站/X）+ "粉丝即传播者"的 UGC 自动运作。

**代表案例（含数据）**
- **雷军 / 小米 SU7（2023-2024）**："最后一次创业"叙事，3 小时一人主讲发布会，全平台输出。发布会观看数亿、微博热搜 50+、24 小时订单破 8.8 万台。
- **罗永浩"交个朋友"还债叙事（2021-2023）**："欠债 6 亿 → 直播还债"的"真还传"系列化故事。首场观看超 4800 万、GMV 超 1.1 亿。
- **俞敏洪 / 董宇辉 · 东方甄选（2022-2024）**："老师转型主播"+ 双语知识带货差异化。3 天涨粉超 1000 万、单日 GMV 破亿。
- **Elon Musk / Tesla "零广告"（2021-2025 全球）**：CEO 用 X 发产品/造话题，Cybertruck 未交付已获数十亿次曝光，Musk 超 2 亿粉丝可影响全球媒体议程。

**可复用模板**
```
个人 IP = 一条贯穿的人设叙事（创业/逆袭/反传统）
        + 发布会/社交账号 = 内容事件
        + 全平台矩阵分发 + 争议性话题
        + 粉丝即传播者的 UGC 自动运作
```

## 第二节 · 联名跨界创意引擎

联名的本质是**借势对方的人群、话题与文化资产**，用最低成本撬动破圈。选对联名对象比执行更重要。

### 2.1 选联名对象的四维评估

| 维度 | 判断标准 | 越高越好的信号 |
|------|---------|---------------|
| **反差值** | 两个品牌的调性/价格/人群距离有多大 | 平民 × 贵族、奢侈 × 平价、传统 × 潮流——反差越大，话题势能越强 |
| **人群重叠** | 双方核心人群是否有可激活的交集 | 既能互相导流，又能扩圈到对方独有人群 |
| **话题潜力** | 联名能否生成一句"可转述的梗" | 自带 UGC 二创空间 / 价格反差梗 / 社交话题势能 |
| **区域文化适配** | 联名符号是否契合目标市场的文化语境 | 借势在地节日/国潮/国宝级品牌，降低传播折扣 |

**实操心法**
- 反差值与人群重叠常成反比，**好联名是在"够反差出话题"和"够重叠能转化"之间找平衡点**。
- 联名周边（杯套/纸袋/盲盒）要被设计成**可收藏、可晒**的社交货币，这是联名能否刷屏的关键。
- 单点联名拼爆款，**高频联名拼矩阵**——用持续话题维持品牌热度不坠。

### 2.2 范式案例（含数据）

**反差值驱动**
- **瑞幸 × 贵州茅台"酱香拿铁"（2023）**：平民咖啡 × 国酒贵族的极端反差，"年轻人的第一口茅台"。首日销量超 542 万杯、销售额破 1 亿，#酱香拿铁# 阅读超 30 亿。创意代理：**奥美（台北 & 厦门）**（有官方案例页）。
- **喜茶 × FENDI"喜悦黄"（2023）**：奢侈品降维联名，"19 元拿下 FENDI"。3 天售超 150 万杯，FENDI 黄刷屏小红书。
- **茅台联名矩阵（×瑞幸/×德芙等，2022-2023）**：高端白酒 × 平民产品做"品牌年轻化"。茅台冰淇淋首日破亿、酱香拿铁首日破亿。

**人群重叠 / 扩圈驱动**
- **泡泡玛特 × 各 IP 矩阵（×肯德基/×可口可乐等，2021-2025）**：用 Molly/Dimoo 自有 IP 把盲盒经济延伸到快消/服饰/美妆，盲盒机制 + IP 高忠诚 + 限量稀缺，爆款上线即售罄、二手翻倍。

**话题潜力 / 高频矩阵驱动**
- **瑞幸 IP 联名矩阵（2023-2025）**：每 2-3 周一个联名（线条小狗/《猫和老鼠》/《黑神话：悟空》），围绕萌系/二创/游戏黑话等情绪触点。2023 年超 20 起、2024 年超 26 起，话题阅读合计超百亿。
- **Barbie 全链联名（2023 全球）**：Warner Bros. + Mattel 主导，**160+ 联名品牌**全品类铺开（技术伙伴 PhotoRoom），把一部电影做成全民粉色浪潮。

**品牌升维 / 区域文化适配驱动**
- **喜茶 × CLOT / × marimekko / ×《上城士》（2024）**：从流量联名转向精品化、文化调性联名，借芬兰国宝级品牌/潮流厂牌制造"懂行"身份认同。

### 2.3 可复用模板
```
联名提案 = 1) 四维打分：反差值 / 人群重叠 / 话题潜力 / 区域适配（各 1-5 分）
         2) 锚定一句"可转述的梗"（价格反差梗 / 第一口体验 / 限量稀缺）
         3) 设计可晒的联名周边作为社交货币
         4) 决定打法：单点拼爆款  or  高频拼矩阵（2-3 周一联）
         5) 区域适配：借势在地节日 / 国潮 / 国宝级品牌
```

## 第三节 · 时代情绪雷达

情绪营销 = **捕捉一个正在涌动的集体情绪 → 用品牌符号承接它 → 让用户在共鸣中完成转发/消费**。雷达的关键是"踩在情绪的上升期"，而非情绪退潮后才跟风。

### 3.1 怎么捕捉时代情绪（通用方法）

- **热词借势**：把当下流行语（"搭子""野性消费"）直接编进品牌叙事，借语言惯性传播。
- **社会情绪洞察**：识别阶段性集体心理（后疫情治愈需求、民族自豪、家乡认同、女性主义），用符号化装置/内容承接。
- **争议即燃料**：主动制造可讨论的争议点（颠覆生肖、争议文案），用对立驱动二次传播——但需价值观可控。
- **节点 + 情绪叠加**：节日/赛事是情绪的天然放大器，把节点情绪与品牌主张绑定。
- **时机判断**：情绪营销要在情绪**上升期**出手；情绪需真实存在，品牌只是"说出大家想说的话"，不可硬造。

### 3.2 分区域情绪共鸣打法

**中国市场 · 民族 / 治愈 / 家乡 / 节日情绪**
- **民族自豪 / 国货情绪**：鸿星尔克"野性消费"（捐款叙事引爆心疼式消费）、白象"拒绝日资 + 雇佣残疾人"（民族品牌 + 残障员工双重共鸣，直播销售额增超 300%、话题超 20 亿）。
- **后疫情治愈情绪**：名创优品巨型"笑脸不倒翁"——"即便身处生活夹缝也要保持微笑"，精准踩中后疫情治愈需求，成世界微笑日影响力最大的品牌装置之一。
- **家乡 / 地域认同**：快手"500 个家乡"第五季——展现 500 个家乡地域文化，唤醒家乡情感认同，系列总播放超 50 亿。
- **春节热词 / 团圆情绪**：伊利 × 贾冰/李现"过年好搭子"（借"搭子"热词 + 明星组合，品效合一，代理：TOPic）；耐克"今年属曼巴"（颠覆生肖 + 科比曼巴精神，用争议驱动传播）。

**全球市场 · 价值观 / 社会议题情绪**
- **女性主义 / 社会议题**：Nike "Never Done"（女性运动员职业与母亲身份的"永不完成"叙事，全球播放超亿次、多获戛纳大奖，代理：Wieden+Kennedy）。
- **诚实 / 反传统情绪**：Burger King "Reclaim the Flame"（黄金档公开认错，承接公众对品牌"诚实"的渴望）；Tesla "零广告"（反传统营销叙事本身成为话题）。
- **公益 / 社会关怀**：BK "Beaten Up Burgers"（用打扁汉堡引出校园霸凌议题，产品体验成社会议题触发点）。

**赛事 / 全球盛事 · 流量红利 + 争议话题**
- **卡塔尔世界杯品牌矩阵（2022）**：蒙牛决赛"M3"文案刷屏、海信"中国第一世界第二"争议广告——借全球盛事流量红利，用争议文案主动制造话题。

### 3.3 可复用模板
```
情绪共鸣 = 1) 雷达扫描：当下有哪个集体情绪正在上升期？
            （热词 / 民族 / 治愈 / 家乡 / 女性 / 诚实 / 公益）
         2) 找品牌与该情绪的真实连接点（不可硬造）
         3) 用一个符号承接：装置 / 神曲 / 短片 / 明星组合 / 公开表演
         4) 区域适配：
            · 中国 → 民族/治愈/家乡/节日热词
            · 全球 → 价值观/社会议题/反传统
            · 赛事 → 流量红利 + 争议话题
         5) 节点叠加放大，情绪上升期出手，争议可控
```

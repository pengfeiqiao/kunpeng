# 全球 + 日韩病毒广告案例库

> 用途：作为互联网广告导演的「打法素材库」与灵感检索表。按病毒元素 / 区域聚类，每条案例给出可迁移套路。检索方式：先按「想要的病毒机制」找分节，再看案例的「可复用套路」。
> 条目格式：**案例名（品牌/国家/年份）** — 病毒元素 | 打法简述 | 传播数据 | 可复用套路
> 覆盖 2021-2025 Cannes Lions / Super Bowl / TikTok Viral / 日韩 CM / 创作者转型，约 90 个案例。

## 一、注意力黑客（强制暂停 / 元广告 / 反套路）

让观众"误以为出错"或必须主动操作，把被动观看变成强制互动。

- **Superb Owl（Reddit / 美国 / 2021）** — 注意力黑客 | Super Bowl 投 5 秒"信号中断"故障画面，逼观众倒回截图阅读致敬 r/WallStreetBets 的文案；仅投 7 个 DMA 市场 | NYT/CNN 海量报道，Cannes Social & Influencer Grand Prix、D&AD、One Show Gold | 极低成本"强制暂停→截图→分享"链路；借势热点文化事件。代理：R/GA
- **QR Code Bouncing Ball（Coinbase / 美国 / 2022）** — 极简解密好奇 | Super Bowl 全程只放一个黑屏弹跳彩色二维码，扫码注册送 $15 BTC | 1 分钟 2000 万+ 访问致官网崩溃，App Store 排名 186→2，6 倍历史流量 | 极简到反创意 = 注意力黑洞；"解谜"心理驱动全民扫码（创意投票倒一却商业爆炸）。代理：Accenture Song
- **Interface Interruption（Tubi / 美国 / 2023）** — 集体恶作剧元广告 | Super Bowl 播到一半假装"切到 Tubi 界面"，让全国观众以为自己误按遥控器 | Twitter 热搜 Top 5（唯一上榜品牌），多座 Cannes Lions | 元广告（广告表演"被误触打开"）；制造"你也被吓到吗"的天然话题。代理：Mischief @ No Fixed Address

## 四、UGC 共创挑战（舞蹈 / 模仿 / 实验）

低门槛动作 + 品牌名/产品天然嵌入，让用户成为内容生产者。

- **Fancy Like（Applebee's / 美国 / 2021）** — 歌曲嵌品牌名 | 蹭 Walker Hayes 爆红歌（歌词含 Applebee's），48 小时内把 TikTok 舞蹈做成电视广告 | 原版 3100 万观看、70 万+ 二创、歌冲 Billboard 第 5 | 品牌名天然嵌入流行歌 + 48h 快速反应。
- **Draw Ketchup（Heinz / 全球18国 / 2022）** — 实验框架共创 | 让人画番茄酱，97% 画成 Heinz 瓶，把涂鸦做成广告素材 | 127 倍 ROI、即时销售+10%、互动率高 1495%；Cannes Effectiveness Grand Prix | "实验"框架自带传播 + 用户涂鸦即广告素材。代理：Rethink
- **Wednesday Dance（Netflix / 全球 / 2022）** — 模仿挑战 | 官方发 Wednesday 诡异僵硬舞段配 Lady Gaga《Bloody Mary》| 官方视频 1 亿+ 播放、1000 万+ 模仿、#WednesdayDance 200 亿浏览 | 剧集片段直接做成可模仿动作 + 反差魔性。代理：Netflix
- **#GucciModelChallenge（Gucci / 全球 / 2021）** — 自发模仿 | 用户用 Gucci 画风滤镜模仿超模走秀，品牌未发起但官方拥抱 | 话题 9.4 亿浏览 | 拥抱用户自发玩法 > 自己造活动。
- **#StackItUp（Pringles / 美国 / 2022）** / **#OreoTwist（Oreo / 美国 / 2023）** — 创意竞技挑战 | 搭薯片塔 / 创意吃法挑战 | Pringles 30 亿浏览 200 万视频；Oreo 50 亿浏览 | 产品仪式化动作 + 低门槛创意竞技。
- **Squid Game 全球营销（Netflix / 全球 / 2021）** — 沉浸装置 + 挑战 | 真人版玻璃桥/巨型人偶/456 号电话亭/椪糖挑战 | 史上最火首播（1.11 亿账号），#SquidGame 670 亿浏览 | 把剧情元素物理化成线下打卡 + 可复刻挑战（椪糖）。

## 五、品牌人设 / "像创作者一样"运营（持续型）

## 十四、创作者转型广告导演（方法论案例）

核心路径：内容能力 → 商业信任 → IP/系列化 → 品牌全案/代言。共性：先用优质内容建立粉丝信任，"广告即内容"让观众主动传播。

- **导演小策 / 张策（中国 / 2021-24）** — 广告即剧情 | 离开"朱一旦"后做 B站"广场往事"，农村大妈黑色幽默短剧，品牌植入融入剧情，自创"刘大鹅"等 IP | B站粉丝 200 万+，单期数百万，"几乎所有品牌都是其广告主" | 土味+黑色幽默审美降维 + 系列化 IP 追更 + 广告融入剧情让观众主动看 + 高密度笑点。路径：编剧→短视频→IP 主理人→品牌定制导演。
- **何同学（中国 / 2021-24）** — 内容 ROI 教材 | 把科技产品做成"创意实验"（升降桌改造等），品牌信息自然嵌入 | 乐歌视频 B站 699.5 万+微博 2340 万 → 乐歌股价单日 +13.51%、市值 +5.46 亿元；单条报价超 300 万 | "内容>广告"观众没意识到恰饭 + 科技实验猎奇 + 一条视频拉股价的硬数据教材。
- **影视飓风 Tim（中国 / 2023-24）** — 商单升级代言 | 天猫首支 AIGC 明星广告片（共建内容非投广告）；为 Rokid AR/猛玛麦克风"破例"代言（产品与创作场景高度匹配） | 4A 媒体盛赞，B站/抖音二创广泛；自有周边年销 2200 万 | 把硬广拍成视觉奇观 + "破例"本身即新闻（稀缺）+ KOL 从接广告升级品牌代言 + 长期主义相互成就。
- **papi 酱（中国 / 2016事件·2021-24 体系）** — 拍卖事件+MCN | 首支广告 2200 万拍卖创纪录，后建 papitube"头部 IP+中腰部矩阵" | 2200 万成全网头条；签约数百创作者 | "网红广告拍卖"本身即传播事件 + 心理锚点比广告更出圈 + 单点创作者进化为可复用商业体系。
- **辛吉飞（中国 / 2022-24）** — 争议流量转化 | "科技与狠活儿"揭食品添加剂走红后转商业化，切片授权多渠道变现 | 抖音千万级粉，年度网络热词 | 争议性=巨大流量 + "我骂过添加剂但推荐好东西"反转叙事 + 切片分销网络。
- **B站头部 UP 主"恰饭"生态（中国 / 2022-24，群体）** — 内容化广告范式 | 品牌定制视频须达普通内容同等品质才被接受，特征：剧情化/硬核制作/梗化 | 官方盘点高质恰饭视频均播超 500 万；品牌定制短剧 2024 同比 +68% | 观众主动投币"反向恰饭"（内容好到催更广告）+ 弹幕二创放大 + 品牌定制短剧成独立品类。
- **乡村自媒体转型（张同学/东北雨姐/李子柒 / 中国 / 2021-24）** — 强人设信任 | 农村生活场景 + 高辨识影像风格获流量后承接合作/做自有品牌 | 张同学单月涨粉千万；李子柒 YT 订阅 1700 万+ | 内容稀缺性（城市用户田园想象）+ 强人设=天然信用背书 + 反差美学。

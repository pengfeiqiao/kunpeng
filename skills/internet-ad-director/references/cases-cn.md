## 十三、可迁移方法论速查

- **国货情绪闭环**：真诚善举/危机清流 → 集体情绪 → "为良心买单"行动 → 热梗放大（鸿星尔克/白象/蜂花）。
- **反差联名公式**：土×潮、奢×平、品类硬碰 → "猝不及防感"→ 周边/杯套即社交货币（瑞幸×茅台/椰树、喜茶×FENDI）。
- **模因低门槛模仿**：洗脑旋律/口号/舞蹈/造梗 → 全民二创飞轮 → IP 沉淀为品牌资产（蜜雪/科目三/79 花西币）。
- **争议即流量**：挑衅话术/社会议题/抄袭风波 → 两极对立 → 双向传播放大（理想 L9、后浪、奥迪）；但民族红线不可碰（宝马 MINI 反面）。
- **稀缺 FOMO**：限量/隐藏款/秒售罄/排队 → 抢购炫耀 → UGC 二次传播（LABUBU、茅台冰淇淋、红包封面）。
- **个人 IP 信任**：创始人/主播人格化叙事（最后一次创业、知识分子、打工人逆袭）→ 人格化信任驱动（雷军、董宇辉、刘畊宏）。
- **技术新奇红利**：低成本高性能/技术奇观/新体验 → 短视频强传播 + 尝鲜分享（DeepSeek、仰望 U8、妙鸭）。
- **城市文旅范式**：素人视频偶然引爆 + 政府教科书式承接 + 人情味叙事（淄博/哈尔滨/天水/村超）。
- **超级 IP 矩阵**：头部 IP × 20+ 品牌跨品类联名 + 限量周边 + 取景地/文旅延展（黑神话、哪吒2）。
- **影视宣发**：养成系全员营业、反向劝退、社会议题降阻力、悬念预热（封神、消失的她、孤注一掷、热辣滚烫）。
- **平台心智**：长期种草闭环/最低价心智/助农情感，靠"普通人帮普通人"信任机制（小红书、拼多多、抖音助农）。

### 平台分工
- **抖音**：起爆/放大主阵地，几乎所有案例的二次爆发场。

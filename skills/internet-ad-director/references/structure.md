# 短视频广告结构生成器

> 用途：把创意策略落地成可执行的短视频结构——前3秒钩子 + 完播率设计 + 转发动机 + 平台节奏。出分镜/提示词前先定好结构。

## 1. 前 3 秒钩子（决定生死）

| 钩子类型 | 示例 | 适用场景 |
|---------|------|---------|
| 问题钩子 | "你有没有遇到过…" | 知识点/痛点类 |
| 冲突钩子 | "两个品牌打起来了" | 联名/争议 |
| 反转钩子 | "你以为是…其实…" | 剧情广告 |
| 视觉冲击钩子 | 粉色/紫色/极致反差画面 | 品牌短片 |
| 名人钩子 | "刘德华说…" | 品牌代言 |

关键：前 3 秒流失率 < 30% 才有机会爆。

## 2. 完播率设计

| 策略 | 说明 | 案例 |
|------|------|------|
| 节奏递进 | 每 3 秒一个小爆点 | 抖音信息流 |
| 悬念叙事 | 不看到最后不知结局 | 反转类 |
| 金句高潮 | 最好的话留到最后 | 情绪共鸣类 |
| 视觉奇观 | 画面本身值得看完 | Shot on iPhone |
| 信息增量 | 每帧有信息，不想错过 | 知识类 |

## 3. 转发动机

| 动机 | 用户心理 | 典型文案/行为 |
|------|---------|--------------|
| 身份表达 | "这就是我" | "这才是格局""这很年轻人" |
| 价值站队 | "我支持这个" | "支持国货""支持女性" |
| 提供谈资 | "你看过这个吗" | "茅台咖啡喝了没" |
| 情感宣泄 | "太感动了" | 流泪转发 |
| 搞笑分享 | "笑死了" | 直接艾特朋友 |
| 实用建议 | "对你有用" | "建议收藏" |

## 4. 抖音/短视频通用节奏

```
开屏 0-2s :  黄金钩子（问题/冲突/视觉冲击）
前段 2-10s:  快速信息（不铺垫，直接给核心）
中段 10-30s: 情绪/剧情展开（持续高能或快→慢）
尾段 30-60s: 情感收束/行动号召（引导评论区互动）

完播关键：
- 前 3 秒流失 < 30%
- 每 5-7 秒一个"再留一下"的钩子
- 结尾留悬念促评论
```

## 5. 平台病毒逻辑差异

| 平台 | 偏好 | 时长/形式 | 注意 |
|------|------|----------|------|
| 抖音 | 强钩子、强节奏、BGM、挑战 | 15-60s 竖屏 | 前3秒定生死，配热门BGM |
| 小红书 | 种草、真实感、图文/口播 | 竖屏+封面文案 | 标题党封面、痛点笔记 |
| 视频号 | 中老年+社交裂变、情感 | 竖屏 | 朋友圈转发驱动 |
| B站 | 长内容、"恰饭"自嘲、硬核 | 横屏中长 | 用户对恰饭包容度高，要有梗 |
| 快手 | 接地气、老铁、强人设 | 竖屏 | 真实粗粝、信任带货 |
| TikTok | 挑战赛、模因、全球化 | 9-30s 竖屏 | 可改编、低门槛二创 |
| YouTube | 故事片、长广告、品牌片 | 横屏可长 | 前5秒留人（skip前） |
| Instagram | 视觉美学、Reels、滤镜 | 竖屏 | 高颜值、可保存 |

## 落地清单（出分镜前自检）

1. 钩子选了哪种？前 3 秒画面/文案是什么？
2. 完播策略是什么？爆点节奏排布好了吗？
3. 主转发动机是哪个？结尾 CTA/悬念是什么？
4. 平台节奏对齐了吗？时长/画幅对吗？
5. 病毒元素（见 viral-elements.md）落到具体镜头了吗？

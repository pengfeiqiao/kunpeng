# 镜头模式路由

本目录用于给分镜选择镜头结构，不负责引擎提示词格式。

## 使用方式

- 建立世界、交代空间、开场定调：读 `establishing.md`
- 对话、视线关系、人物关系：读 `dialogue.md`
- 追逐、冲突、打斗、强运动：读 `action.md`

## 写入分镜时必须落到字段

- 景别
- 运镜
- 主体动作
- 情绪外化
- 空间关系
- 时长
- 关联角色/场景/道具

## 冲突优先级

镜头模式只决定“怎么拍”，不覆盖角色一致性、导演 DNA 和 Seedance 权威模板。

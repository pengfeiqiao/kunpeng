# @ 图片引用规则

## 传图顺序 = @ 引用编号

| 传入顺序 | 提示词中引用 | 说明 |
|----------|-------------|------|
| 第 1 张 --image | @图片一 | **始终是场景参考图** |
| 第 2 张 --image | @图片二 | 角色/资产图 |
| 第 3 张 --image | @图片三 | 角色/资产图 |
| 第 4 张 --image | @图片四 | 角色/资产图 |
| 第 5 张 --image | @图片五 | 角色/资产图 |

## 强制规则

**有资产图就必须在提示词中有对应的 @ 引用。**
每张上传到「资产图」字段的图片，都必须在「视频提示词」中出现对应的 `@图片N`。

## 检查方法

对每个镜头记录，逐条检查：
1. 查「资产图」字段有哪些附件文件
2. 查「视频提示词」字段是否包含所有文件的 @ 引用
3. 遗漏的在对应的描述文字后面加上 `@文件名`

## 容易遗漏的场景

- 配角/次要角色：即使只出现一次也要 @ 引用
- 手持物品/道具：如果是独立资产图，必须 @ 引用
- 多镜头合并：每个子镜头行内独立写 @ 引用，同一物体在不同子镜头出现要重复写
- 场景图：始终是 @图片一，每个提示词都必须有

## 两阶段 @ 引用规则（飞书表格 vs 生视频提交）

@ 引用分为两个阶段，使用不同的格式，**严格区分**：

### 阶段一：飞书表格中（给用户看的）

在飞书多维表格的「视频提示词」字段中，**@ 引用必须使用具体文件名**：

```
分镜场景设定在：月下瓜田 @S1_月夜远景_v8.png
镜头1 6s [大远景/固定] 深蓝夜幕下，圆月高悬 @S1_月夜远景_v8.png，瓜田静谧。
镜头2 5s [近景/平移] 闰土@PT1_闰土_v1.png手持钢叉@PR1_钢叉_v3.png，盯住前方。
```

### 阶段二：生视频提交时（给 dreamina / rhtv API 的）

提交视频生成任务时，根据 `--image` 上传顺序，把 @具体文件名**临时替换**为 @图片N：
- `@S1_月夜远景_v8.png` → `@图片一`（第 1 张上传的场景图）
- `@PT1_闰土_v1.png` → `@图片二`（第 2 张上传的资产图）
- `@PR1_钢叉_v3.png` → `@图片三`（第 3 张上传的资产图）

替换后提示词末尾加注释：
```
【生图注释】生成视频时根据实际上传图片顺序，将@具体文件名改为@图片一/@图片二格式。此注释不写入视频提示词。
```

### 阶段二红线（提交前必查）

- 转换后**逐条核对**：最终提示词里所有图片 @ 引用必须是 `@图片N` 位置编号
- **不得残留**任何文件名（`.png`/`.jpg`）、自定义名（`@人一`/`@物一`）、或把 `@音频一` 当图片占位
- 提交前自检：通篇搜 `.png` / `.jpg` / `@人` / `@物` / `@音频`（作图片引用时）应为 **0 命中**
- Seedance API 只认 `@图片一`~`@图片五`，残留其他写法一律识别失败

## 音频 @ 引用（不占图片编号）

- 音频**不写 @图片/@音频 作占位引用**，用文字描述音色：`用@音频一的音色用{方言}唱/说：{内容}`
- `--audio` 第1个 = @音频一，**仅在文字里引用**，不参与 @图片N 编号体系
- ❌ `用女主年轻声音的音色` → ✅ `用@音频一的音色`

## 官方特殊符号规范（Seedance 2.0）

提示词用符号区分信息类型：**台词 `{}`**、**音效 `<>`**、**音乐 `（）`**、**字幕 `【】`**。
- 台词写法：`人物@图片二用@音频一的音色唱：{歌词内容}`
- 完整规范 → 读 prompt-templates/seedance/single-shot.md

## 多主体定义（官方，防双胞胎/ID 漂移）

多人物同画面**必须分别定义唯一标签并贯穿使用**，否则易出现"双胞胎"：
- `将@图片N中的[2-3个稳定静态特征]定义为<主体N>`，后续持续用同一标签
- 或人名后标注对应图：`张三（对应图片一）将存折扔向李四（对应图片二）`
- 人物参考图优先单人独立照，**不用三视图/多视图**
- 末尾可加全局约束：`禁止出现外形着装完全一致的人物，禁止同款分身/双胞胎`

## @ 引用编写前置检查

**在写任何 @具体文件名 引用之前，必须先 `ls` 确认文件确实存在：**
```bash
ls /path/to/workspace/images/S1_月夜远景_v8.png
ls /path/to/workspace/assets/
```
**绝对禁止**凭记忆或命名规则猜测文件名。

## 反例（错误写法）

```
分镜场景设定在：长安火车站 @图片一
镜头1+2 13s 时间: 黄昏。 [全远景/固定] 长安蒸汽火车站外景。陈墨站在站台望向远方。
```
→ 陈墨有资产图但提示词中没有 `@图片二`，错！

## 正例（正确写法）

```
分镜场景设定在：长安火车站 @图片一
镜头1+2 13s 时间: 黄昏。 [全远景/固定] 长安蒸汽火车站外景。陈墨@图片二站在站台望向远方。
```

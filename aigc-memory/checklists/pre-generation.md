# 生成任务提交前检查清单

每次调用 Seedance / 即梦 / 生图 API 前，**必须逐条自检**：

---

□ **1. 参考图传了几张？顺序和 @ 编号一一对应了吗？**
   第1张→@图片一（场景），第2张→@图片二，...，第5张→@图片五

□ **2. 有真人/角色素材吗？**
   如果有 → 必须加 `--param "realPersonMode=true"`

□ **3. 所有上传的资产图在提示词里都有 @ 引用吗？**
   逐张图片比对提示词，确保无遗漏

□ **4. 接口选对了吗？**
   传图 → `multimodal-video`
   不传图 → `text-to-video`
   （text-to-video 不支持传图！）

□ **5. 参数完整吗？**
   duration / resolution / ratio / generateAudio 是否已设置？

□ **6. 飞书表格中的提示词格式正确吗？**
   格式：`分镜场景设定在 + 镜头行`，不是自由发挥？
   飞书表格中 @ 引用用具体文件名（如 @S1_月夜远景_v8.png）
   **注意**：生视频提交时才把文件名换成 @图片一/@图片二！

□ **7. 用户确认了吗？**
   方案有没有先给用户看过？用户说"做"了吗？

□ **8. 提示词模板类型选对了吗？**
   飞书表格中：`分镜场景设定在：{地点} @文件名.png` + `镜头行`
   不是 GPT-Image-2 的章节格式（角色设定+技术参数+约束）！
   GPT-Image-2 模板 → 仅用于生图，Seedance 模板 → 仅用于生视频

□ **9. @ 引用中的文件名在文件系统中确实存在吗？**
   每个 @具体文件名 引用前都 `ls` 确认过吗？
   不是凭记忆/命名规则猜的文件名吧？

□ **10. 场景图是按每个镜头的景别分别匹配的吗？**
   大远景/远景→远景图、中景→中景图、近景/特写→特写图
   不是所有镜头用同一张场景图吧？

□ **11. 批量操作前做过单条验证吗？**
   先插 1 条 → 验证格式正确 → 再批量执行
   没有直接批量全写吧？

□ **12. 使用不熟悉的 lark-cli 命令前看过 --help 吗？**
   不确定的参数名/格式先查 --help，不要靠猜

□ **13. VO 行用对了吗？**
   画面内人物当场说/唱 → 写进镜头描述行
   只有旁白/画外内心独白才用 VO 行
   没把画面内对白错误提成 VO 行吧？

□ **14. 提交 API 的提示词 @ 引用全是 @图片N 吗？**
   通篇无文件名（.png/.jpg）、无自定义名（@人一/@物一）、无 @音频 当图片占位残留？
   （表格阶段可用文件名，但提交前必须全转成位置编号）

□ **15. 音频是用文字引用的吗？**
   写成 `用@音频一的音色用{方言}唱/说：内容`，不是 @音频 占位？

□ **16. select 字段值都是已存在选项吗？**
   没有用选项列表里不存在的值（会上传失败）？

□ **17. 记录粒度和最终生成维度对齐吗？**
   表格按单镜头还是合并视频建的，和实际生成维度一致？

---

全部通过后再执行生成。任何一项未通过 → 修正后再提交。

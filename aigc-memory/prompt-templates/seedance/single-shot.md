# Seedance 2.0 单镜头视频提示词模板

> 官方核心理念：Seedance 2.0 是「多模态 AI 导演」，把提示词拆成**空间层**（画面有什么）和**时间层**（如何随时间变化）。
> 好提示词是**工程型指令**（谁/在哪/做什么/镜头怎么动/什么顺序），不是文案型形容。

## 进阶公式（官方）

```
精准主体 + 动作细节 ＋（建议）场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```
- **必需**：精准主体、动作细节
- **建议**：场景环境、光影色调、镜头运镜、视觉风格、画质、约束条件
- 顺序逻辑：先锁「谁」在「干什么」→ 再交代「在哪」「什么氛围」→ 再说「怎么拍」→ 最后用风格/画质/约束收紧。

## 标准格式（项目惯例 + 官方四层组织）

```
分镜场景设定在：{地点} @图片一
{人物}@图片N（VO）：旁白/画外内心独白内容（仅旁白才写此行，没有则跳过）
分镜具体动作描述：
镜头{编号} {时长}s 时间: {时间}。 [{景别}/{运镜}] {画面描述：运镜→动作表情→位置→音频} {人物/物体@图片N}
```

每个镜头按官方四层顺序组织：
1. **运镜/切换**：如"全景缓慢推近""固定机位""镜头切至…"
2. **主体动作与表情**：核心角色/物体的关键动作、神态变化
3. **位置/空间变化**：主体所处场景、位置、空间关系
4. **音频信息**：音效、人声、背景音乐

> ⚠️ 时长说明：保留 `{时长}s` 用于控制节奏/总时长，但官方提示——**模型对精确秒数（尤其 0–3s）支持不稳定**，时长作节奏参考、不强依赖；总时长以 `--param duration` 为准。

## 特殊符号规范（官方，重要）

提示词中用符号区分信息类型，有助模型准确理解：

| 信息类型 | 符号 | 示例 |
|---------|------|------|
| 台词 | `{}` | `{你好，世界}`；小语种标语种：`用日语说道{こんにちは}` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 字幕 | `【】` | `【第一章：启程】` |

- 台词 + 音色写法：`人物@图片二用@音频一的音色用湖北宜昌西南官话方言唱：{歌词内容}`
- 画面内对白/唱词写进镜头描述（不另起 VO 行），台词部分用 `{}` 包裹。

## 示例

```
分镜场景设定在：诗云塔三层·中庭 @图片一
分镜具体动作描述：
镜头9-1 4s 时间: 夜晚。 [特写/固定] 陈墨@图片二缓慢抬头看齿轮@图片三从底层到顶层依次加速，蒸汽猛烈喷出，铜管@图片四共鸣朗诵{君不见黄河之水天上来}，<蒸汽嘶鸣声>。
```

## 示例（画面内对白/唱词写进镜头描述，台词用 `{}`）

```
分镜场景设定在：峡江江面·黄昏 @图片一
分镜具体动作描述：
镜头3-2 12s 时间: 黄昏。 [中景/缓推] 两船缓慢靠近，屈德厚@图片二站船头，借扶船舷的动作顺势挺胸，用@音频一的音色用湖北宜昌西南官话方言唱：{歌词内容}。江风掀衣，对面船工@图片三缓缓抬头望来。（背景江水声与号子声交织）
```

## 动作描述要求（官方）

- **肢体细化 + 程度量化**：动作具体到手/腿/头/肩背，补幅度/速度/力度。例：缓慢抬手、快速转头、用力蹬地、微微低头。
- **优先低缓连续小动作**：尽量规避狂奔、大跳、剧烈翻滚等高爆发大动态（易崩坏）。例：缓慢行走、轻轻抬手、顺势坐下。
- **补动作过渡衔接**：写明前后动作惯性承接。例：借转身惯性顺势抬手、从停顿自然过渡到举手。
- **情绪具象外化**：用身体细节表现情绪，不要"很悲伤""非常愤怒"这类抽象词。

| 抽象情绪 | 外化为动作细节 |
|---------|--------------|
| 悲伤 | 低头、肩膀微颤、眼眶泛红、手指攥紧衣角、泪水打转未落 |
| 喜悦 | 嘴角上扬、眉眼舒展、脚步轻快、原地转圈 |
| 紧张/焦虑 | 频繁看表、手指敲桌、呼吸急促、眼神闪躲、啃指甲 |
| 愤怒 | 双拳紧握、下颌紧绷、胸口起伏、眼神如刀、从牙缝挤话 |
| 释然 | 长舒一口气、肩膀放松、淡淡微笑、抬头望远 |

## 表演层次与行为目的（人物表演默认标准）

- **情绪按时间轴分三层推进**：触发期（信息抵达瞬间：表情凝固、瞳孔变化、呼吸暂停或变浅）→ 发酵期（核心肌群缓慢激活，出现吞咽、手指蜷缩、肩膀轻耸等下意识小动作）→ 释放期（表情展开到峰值，身体姿态与情绪和解或对抗）。禁止开关式瞬变（上一秒平静下一秒狂喜/暴怒）。
- **三层联动**：面部（量化幅度/速度，如嘴角上扬12°、每4秒缓慢眨眼）+ 呼吸躯干（呼吸变浅、喉结滚动、肩背塌下）+ 手部重心（指节收紧、摩挲衣角、重心前移/后撤）。
- **行为目的**：主要动作写清角色此刻的动机（想隐藏/确认/靠近/疏远什么），落成可见细节（"视线快速移开又偷瞄回去"= 掩饰在意）。同一情绪按性格锚点演出差异，强度匹配剧情量级。
- **反应镜头**写听者的微反应：短暂停顿、笑容凝固、视线回避或逼视。

### 默认禁止 AI 短剧/漫剧风表演

除非用户明确要求该风格，人物表演一律禁止：瞪眼/瞪大双眼、嘶吼咆哮、五官扭曲、夸张张嘴、表情包式脸谱化表情、开关式情绪瞬变、嚎啕大哭/泪水飞溅（应写眼眶泛红、泪珠聚集未落、下唇咬痕等克制表达）、无动机甩头/跺脚/挥臂/暴跳如雷、邪魅一笑/挑眉坏笑等套路化网感表情、磨皮塑料感（应保留真实皮肤纹理）。

## 运镜写法

- 直接用标准运镜术语：中景、特写、全景、缓慢推镜、平稳横移、固定镜头等。
- **一个镜头里只指定 1 种运镜**，不要同时推拉摇移（会增加画面不稳定）。

## 画质 / 风格 / 约束词（官方，片尾必带）

- **画质**：高清，细节丰富，电影质感，色彩自然，光影柔和
- **风格**：统一美术调性（如 赛博朋克冷蓝紫色调 / 复古胶片 / 日系清新 / 项目风格串）
- **约束词（必带，规避瑕疵）**：
  - 避免字幕：`保持无字幕` / `避免生成任何文字或字幕`
  - 避免 Logo：`不要生成Logo`
  - 避免水印：`不要生成水印`
  - 防风格漂移：明确写目标风格（如 `2D日漫风格`、`3D国风CG`），尤其参考图偏写实时
  - 人物稳定：`人物面部稳定不变形，动作自然流畅，无卡顿无闪烁`
  - 表演克制：`表演克制真实，情绪有层次递进，无瞪眼嘶吼等夸张程式化表情`

## @ 图片引用规则

| 传入顺序 | 提示词中引用 | 说明 |
|----------|-------------|------|
| 第 1 张 --image | @图片一 | 场景参考图（必须第一张） |
| 第 2 张 --image | @图片二 | 角色/资产图 |
| 第 3 张 --image | @图片三 | 角色/资产图 |
| 第 4 张 --image | @图片四 | 角色/资产图 |
| 第 5 张 --image | @图片五 | 角色/资产图 |

- 提示词中写 **@图片一 / @图片二 等中文数字**，不要写文件名。
- 每张传入的图都必须在提示词中有对应的 @ 引用，逐张核对。
- **提交 API 的最终提示词**：所有 @ 引用必须是 `@图片N`，绝不能残留文件名 / `@人一` / `@物一` / `@音频一` 作图片占位（API 只认位置编号）。

## 主体定义（官方，防 ID 漂移/双胞胎）

- 简单场景未定义主体时：每次用 `主体@图片N` 绑定（如 `张三@图片一`）。
- 多主体/复杂场景：先定义唯一标签并贯穿使用——`将@图片N中的[2-3个稳定静态特征]定义为<主体N>`。例：将视频1中高个子男人定义为警察，矮个子男人定义为小偷，后续持续用"警察""小偷"指代。
- 特征用 2–3 个清晰稳定的静态特征（服饰/发型/外观/类别），确保唯一可识别，避免矛盾特征。

## 音频引用（音频不占图片编号）

- 音频**不写 @音频 占位**，用文字描述音色：`用@音频一的音色用{方言}唱/说：{内容}`
- `--audio` 第1个 = @音频一，仅在文字里引用，不参与 @图片N 编号。
- ❌ `用女主年轻声音的音色` → ✅ `用@音频一的音色`
- 音色不准时补音色特征描述，如：`用@音频一低厚温润带细碎颗粒感中年男声的音色说`

## VO 行 vs 画面内声音（易错！）

- **VO 行**（`人物@图片N（VO）：内容`）**仅用于**旁白、画外内心独白。
- **画面内人物当场说/唱** → 直接写进镜头描述行，台词用 `{}` 包裹，**不另起 VO 行**。

## 素材配置策略（官方）

- 四种功能角色：①角色锚定（锁外观）②场景定调（锁环境风格）③运镜参考（锁镜头语言/节奏）④节奏氛围（音频控情绪音色）。
- **推荐 4–5 个素材**：角色图 1–2 张（面部特写/全身）+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段。
- **不要用满素材上限**（过多致特征优先级混乱、风格冲突、主体识别模糊）。
- **人脸用大头照 + 全身照，不用多视图**（多视图易被识别为多个主体，加剧 ID 漂移/双胞胎）。
- 越需精准参考的素材，放提示词越靠前。
- 参考人物 > 4 人时：分组生图（每组 ≤4 人）再用分组图生视频。

## 接口选择（关键！）

| 场景 | 端点 | 说明 |
|------|------|------|
| 有参考图 | `bytedance/seedance-2.0-global/multimodal-video` | 支持多张 --image |
| 无参考图 | `bytedance/seedance-2.0-global/text-to-video` | 纯文本生成 |
| 有真人素材 | multimodal-video + `realPersonMode=true` | **必须加此参数** |

## 调用模板

```bash
python3 runninghub.py \
  --api-key "<key>" \
  --endpoint "bytedance/seedance-2.0-global/multimodal-video" \
  --image "/path/scene.jpg" \
  --image "/path/character1.jpg" \
  --image "/path/character2.jpg" \
  --prompt "分镜场景设定在：{地点} @图片一
分镜具体动作描述：
镜头{编号} {时长}s 时间: {时间}。 [{景别}/{运镜}] {画面描述} {人物@图片N用@音频一的音色说：台词用花括号}
全程高清电影质感，光影柔和；人物面部稳定不变形；保持无字幕，不要生成Logo和水印。" \
  --param "duration={4~15}" \
  --param "resolution=720p" \
  --param "ratio=16:9" \
  --param "generateAudio=true" \
  --param "realPersonMode=true" \
  -o "./output.mp4"
```

## 常用参数

| 参数 | 值 | 说明 |
|------|-----|------|
| duration | 4-15 | 视频总时长（秒），节奏以此为准 |
| resolution | 720p / 1080p / 2k / 4k | 分辨率 |
| ratio | 16:9 / 9:16 / 1:1 / 4:3 / 21:9 | 画面比例（横屏生字幕概率低于竖屏） |
| generateAudio | true / false | 自动生成配音 |
| realPersonMode | true | 启用真人素材（有人物必加） |

## 语言规范

- 台词语言统一，避免中英混用（专有名词除外）。
- 小语种台词需标注语种。
- 多音字/生僻字易读错 → 用同音常用字替换（如"螭龙山"→"吃龙山"）。

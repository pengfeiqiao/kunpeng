# Seedance 2.5 新版：人物对话与导演提示词

这是鲲鹏的新版写作规范，不是供应商官方参数承诺。普通对话未指定格式时使用；已选经典版的项目保留原格式。只编辑提示词不执行付费生成，不新增首尾帧流程。

## 六段结构

1. **素材身份**：实际素材按提交次序声明人物/场景/声线/运动参考各管什么。没有附件就写无参考，不猜编号。
2. **空间与初始站位**：场景锚点、人物之间的方向和距离、朝向、视线、已有前中后景与对话轴线。屏幕左右不能替代世界位置。
3. **一句话概述**：交流中发生的可见变化，保持原剧情。
4. **时间戳动作与机位**：按实际时长安排镜头、对白、表演、焦点和切点，完整覆盖时间。简单镜头简写，不凑固定字数或子镜头数。
5. **物理与一致性**：身份、座位、道具、视线、动作连续与口型归属。涉及驾驶人物时明确正确系好安全带。
6. **视觉与声音**：有依据的光线、景深、真实声线、环境声、对白及需要的声画衔接。无原文依据不新增台词/旁白/音乐；默认不额外加字幕。

## 对话镜头怎么选

先判断谁在争取什么、谁的回应改变关系，再选观看位置。不按说话轮次自动左右切，也不默认两个人说完所有话才切。

- 双人中景或主镜头：观众需要了解双方距离、阻隔、进退时使用。已有空间清楚时不必每段重新建立。
- 过肩正反打：写“从甲肩后看乙”，而不是只写“反打”。明确甲的肩背在前景哪侧、虚焦程度，乙在中景的朝向与眼神落点；背景保留可识别的空间锚点。反向机位只换观察位置，不交换座位。过肩不是要求前景占固定百分比。
- 干净单人近景：关键决定、疏离或隐瞒需要隔开另一方时可拿掉肩部前景，不必所有镜头都带遮幅。
- 听者反应：关键字落下时可提前切给听者，给信息落地和策略改变留空间。说者声音可以继续，但听者不能跟着同步口型。
- 双人移动或长镜头：用户明确要求、或关系变化主要靠持续走位时保留；写谁走、谁留、谁挡住去路、焦点何时交接，不伪装成没有调度的固定双人拍摄。

常规对话保持轴线同侧与视线匹配。需要越轴时用可见移动或重新建立空间说明意图，不把技术名词当禁令。多人对话先锁定每个人的对象与空间关系，不能套用两人镜序而漏掉第三人的反应。

## 遮幅要帮助看关系

优先使用已有肩背、门框、窗沿或空间层次。它们提供距离感、窥视感或关系阻隔，但不为“电影感”凭空添加角色和道具。避免覆盖关键口型、眼神、手部动作，避免大面积虚焦遮挡让身份无法判断。背景保持可辨识层次；不是所有画面都必须极浅景深。

## 表演与说话语气

每个重要节拍内部判断“目标—阻碍—尝试—回应”，最终提示词写可见、可听的部分，不输出长篇心理分析：

- 同一句话可能是在试探、安抚、拖延、逼问。选择符合文本的行动，不能凭空改变人物关系。
- 给相关词重音、停顿位置、语速变化或句尾走向；保留说话者已有声线与方言。轻声不必等于温柔，大声不必等于愤怒。
- 听者的目光、动作中止、迟疑或接话时机来自具体触发，不是每句都机械吞咽、咬唇和攥拳。
- 表演可克制，也可按剧情有强烈反应；不要求所有情绪都经历完整释放，不编造肌肉角度和眨眼周期。
- 台词原句不变，不把表演注释读出来。停顿与反应也占时间；读不完时提出拆段/延时，不擅自删词或机械倍速。

L-cut 是前镜声音延续到后镜画面；J-cut 是后镜声音先于其画面进入。实际使用时写清声音来自谁、从哪句开始，不能只堆术语。画外延续不等于新增旁白；对白可跨切保持一个连续声音事件，不能重复半句。

## 原创示例：同一句问话先看说者，再看听者

假设已有剧本只含甲“你还走吗？”、乙“等你说完。”，两人隔桌坐着。本例10秒为原创节拍建议，不是固定规格；实际生成时按工具能力核对。未提供参考时不填 @图片。

【素材身份】无外部参考，沿用本段已确定的甲、乙人物设定。
【空间与初始站位】甲坐桌边靠窗一侧，乙坐其对面；两人不换座。机位保持对话轴线同侧，视线朝向对方。桌面只保留原有物件。
【一句话概述】甲试探对方是否离开，乙选择留下把话听完。
【时间戳动作与机位】
0–3秒：从乙肩后看甲的过肩近景，乙肩背虚焦位于前景左下，不挡甲眼睛和嘴。甲先看向乙，身体不前扑；问“你还走吗？”，音量较低、语速平常，重音轻落在“还”，句尾带试探，不拖成哭腔。
3–6秒：在甲问句收尾时切到乙的反向过肩近景，甲肩背在前景右下；甲最后的声音自然延续，仍属甲，乙不跟口型。乙先停住原有小动作，看回甲，留一个能看清反应的停顿，再说“等你说完。”语速略放缓，“等”字明确但不加重攻击，句尾落稳。
6–10秒：乙句尾切给甲的干净近景，乙声音自然收完。甲接住目光，原本绷住的肩稍放松，缓缓呼气；没有新增台词。镜头留给变化发生，不机械推拉或突然流泪。
【物理与一致性】人物面容、服装、座位与视线稳定；换机位不交换位置，嘴型只属于当时说话者，无新增人物或物件。
【视觉与声音】沿用窗边现有自然光方向，背景保留空间层次。两人声线稳定，音量符合隔桌交谈距离，保留轻微室内底噪；无额外字幕、配乐或旁白。

如果用户只改语气，保留原镜序；只改机位，保留台词和原声音节拍。不得套用本例新增“留下”的剧情。

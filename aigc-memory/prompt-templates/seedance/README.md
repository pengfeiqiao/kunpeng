# Seedance 权威模板入口

本目录是鲲鹏唯一权威 Seedance 视频提示词规范。其它 skill、工坊、画布、旧 AIGC Project 中出现的 Seedance 写法只作为创作建议；若发生冲突，以本目录为准。

## 模板选择

- 默认用 [Seedance 2.5 新版](universal.md)：普通对话未指定格式时，以及选择 universal 的画布/工坊，按六段式组织素材、空间、时间轴、物理和声音。
- 用户明确指定经典版，或现有项目/单镜选择 legacy 时，使用 `single-shot.md` / `multi-shot.md`。旧模板内容保留，不迁移或覆盖已有提示词。
- 提示词格式与生成引擎分离：新版排版不自动切换付费模型；真实参数范围仍以当前注册工具为准。
- 人物对白按新版中的对话调度方法规划正反打、听者反应、前景层次、表演和语气；长镜头是有意选择，不是默认遗漏切镜。

## 提交前红线

1. 最终提交 API 的提示词里，所有图片引用必须是 `@图片一`、`@图片二` 这类位置编号。
2. 不得残留 `.png`、`.jpg`、文件名、`@人一`、`@物一` 等非位置编号。
3. 音频不占图片编号，只能写成 `用@音频一的音色...`。
4. VO 行只用于旁白或画外内心独白；画面内对白/唱词写进镜头行。
5. 经典版保留原有台词/音效标记；新版用明确角色名、原句引号和声音说明，不把六段标题误当字幕指令。
6. 每张上传参考图都必须在提示词中被对应 `@图片N` 引用。
7. 一个镜头只指定一种主要运镜，避免同时推、拉、摇、移。
8. 人物表演优先遵守 `universal.md` 的对话与表演方法。旧版参考 `single-shot.md` 的「表演层次与行为目的」标准（情绪触发→发酵→释放、动作有动机）；默认禁止瞪眼、嘶吼、嚎啕大哭、开关式情绪瞬变、夸张肢体、邪魅坏笑等 AI 短剧/漫剧风表演，除非用户明确要求该风格。

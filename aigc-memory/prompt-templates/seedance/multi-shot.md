# Seedance 2.0 多镜头合并视频提示词模板

> 官方理念：复杂视频最理想形态是**时间轴化分镜**——把视频拆成几个分镜，按事件顺序动态描述每个分镜：谁 + 在哪 + 做什么 + 镜头怎么动 + 音频。

## 适用场景

- 多个短镜头合并为一个视频文件
- 同一场景不同视角的快速切换
- 蒙太奇/快剪序列
- 带 VO（画外音）的跨镜头叙事

## 标准格式

```
分镜场景设定在：{地点} @图片一
{人物}@图片N（VO）：旁白/画外内心独白内容（仅旁白才写）
分镜具体动作描述：
镜头{编号}-1 {时长}s 时间: {时间}。 [{景别}/{运镜}] {运镜→动作表情→位置→音频} {物体@图片N}
镜头{编号}-2 {时长}s 时间: {时间}。 [{景别}/{运镜}] {运镜→动作表情→位置→音频} {物体@图片N}
镜头{编号}-3 {时长}s 时间: {时间}。 [{景别}/{运镜}] {运镜→动作表情→位置→音频} {物体@图片N}
```

## 关键规则

1. 场景设定行只写一次，在提示词最开头
2. 每个子镜头独立一行，编号用 `{镜号}-1`、`{镜号}-2`、`{镜号}-3` 区分
3. VO 行放在场景设定行之后、镜头行之前——**仅旁白/画外内心独白才用 VO 行**
4. 每个子镜头行的 @ 引用独立写，即使同一物体在多个子镜头出现也要重复写
5. 每镜按官方四层组织：运镜/切换 → 动作表情 → 位置/空间 → 音频
6. 一个镜头只用 **1 种运镜**（不要同时推拉摇移）
7. 所有参数（duration 等）取总时长

> ⚠️ 时长说明：保留 `{时长}s` 控制节奏，但官方提示模型对精确秒数支持不稳定，作节奏参考、不强依赖；总时长以 `--param duration` 为准。

## 特殊符号规范（官方，重要）

| 信息类型 | 符号 | 示例 |
|---------|------|------|
| 台词 | `{}` | `{你好，世界}`；小语种标语种：`用韩语说{밥 다 됐어요?}` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 音乐 | `（）` | `（背景中播放着紧凑的鼓点）` |
| 字幕 | `【】` | `【第一章：启程】` |

画面内对白/唱词写进对应镜头描述，台词部分用 `{}` 包裹。

## 多主体定义（官方，防双胞胎/ID 漂移）

多人物场景**必须分别定义唯一标签并贯穿使用**，否则易出现"双胞胎"（同画面两个相同人物）：

- 定义：`将@图片N中的[2-3个稳定静态特征]定义为<主体N>`
- 后续持续用同一标签指代（如定义"警察""小偷"后全程用该词）
- 或在人物名后标注对应图：`张三（对应图片一）将存折扔向李四（对应图片二）`
- 末尾加全局约束：`视频全程禁止出现外形、着装完全一致的人物，禁止同款分身/双胞胎，同一画面仅保留单个对应人物`
- 人物参考图优先单人独立照，**不用三视图/多视图**

## 动作描述要求（官方）

- 肢体细化 + 程度量化（缓慢抬手/快速转头/用力蹬地）
- 优先低缓连续小动作，规避狂奔大跳剧烈翻滚
- 补动作过渡衔接（借转身惯性顺势抬手）
- 情绪用身体细节外化（低头肩颤/嘴角上扬/双拳紧握），不用"很悲伤""很愤怒"抽象词

## 画质 / 风格 / 约束词（片尾必带）

- 画质：高清，细节丰富，电影质感，光影柔和
- 风格：统一美术调性（项目风格串）
- 约束词：`保持无字幕` / `不要生成Logo` / `不要生成水印` / 明确目标风格防漂移 / `人物面部稳定不变形，无穿模无卡顿`

## 提交 API 红线

提交给 API 的最终提示词，所有图片 @ 引用必须是 `@图片N` 位置编号，绝不能残留文件名 / `@人一` / `@物一` / `@音频一` 作图片占位。

## 示例

```
分镜场景设定在：诗云塔三层·中庭 @图片一
陈墨@图片二（VO）：长安城三百年前改了蒸汽历。钟楼报时不用钟，用诗。
分镜具体动作描述：
镜头9-1 4s 时间: 夜晚。 [蒙太奇/快速交叉剪辑] 齿轮@图片三从底层到顶层依次加速，蒸汽猛烈喷出，铜管@图片四共鸣朗诵{君不见黄河之水天上来}，陈墨@图片二缓慢抬手站在齿轮前，<蒸汽轰鸣声>。
镜头9-2 4s 时间: 夜晚。 [幻象/慢动作] 蒸汽中凝聚出李白@图片五幻象——宽袍大袖、举杯对月，持续2秒后消散，陈墨@图片二微微睁大眼睛。
镜头9-3 3s 时间: 夜晚。 [中景/固定] 齿轮@图片三缓慢减速，蒸汽消散，压力表回落，陈墨@图片二顺势擦手转身。（背景蒸汽机低鸣渐弱）
```

## 音频引用（音频不占图片编号）

- 音频**不写 @音频 占位**，用文字描述音色：`用@音频一的音色用{方言}唱/说：{内容}`
- `--audio` 第1个 = @音频一，仅文字引用，不参与 @图片N 编号

## VO（画外音）写法

```
人物名@图片N（VO）：画外音内容...
```

VO 行放在场景设定行之后、第一个镜头行之前。**仅旁白/画外内心独白用此行**；画面内人物当场说/唱要写进镜头描述（台词用 `{}`），不用 VO 行。没有 VO 则跳过此行。

## 视频延长 vs 分段拼接（官方）

- **连续长镜头（视频延长）**：适用单一场景"文戏"——长对话、情绪递进、单一路径移动，实现一镜到底沉浸感。
- **场景/动作转折（分段拼接）**：适用剧情转折或复杂快速"武戏"——追逐、打斗、蒙太奇，独立生成片段再剪辑组合。
- 实际常结合：先延长生成连贯对话，再拼接空镜/转场。

## 参数注意

- `duration` 设各子镜头时长之和（上例 4+4+3=11s，所以 `--param "duration=11"`）
- 所有子镜头必须在同一场景（场景图相同），否则应拆为多次调用
- 其余参数同 single-shot 模板

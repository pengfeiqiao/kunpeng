# 工作台体验精修

## 现场调研与取舍

2026-09-05 复核用户实测后的工作台界面，现场确认信息层级与操作密度问题。

- 内容栏采用多层折叠：每个元素、每个镜头下都有自己的说明与素材组，允许多个元素同时展开。不是将所有角色/场景挤在一行横向滚动。
- 浏览态优先展示媒体；打开提示词后，媒体缩成小预览，正文成为主要编辑区，参考、模型规格和生成操作保持相邻。
- 对话栏独立滚动，产物与执行结果在消息中展示；字号偏紧凑，主次更多依赖字重、颜色、留白而不是夸大的标题。
- 面板有窄间隔、独立边框与小圆角。不会把每一层内容都套成厚重的卡片。

毛玻璃、可调栏宽与具体动效时长是本次结合用户要求做的鲲鹏设计。保留鲲鹏名称、专业画布/剪辑底层与现有功能。

## 本轮实施范围

1. 新项目空白：`ensureDefaultColorPalettes` 只保留既存色卡，不从默认预设植入项目。旧色卡、用户修改、历史候选不删除；空项目仍进入新工坊。
2. 创意接应：显式创建时将原始创意及附件加入项目助手队列，不只存项目字段。不在项目加载时自动重放；完成或提交不明的队列项不能被同一交接重新提交。
3. 内容树：剧本为可展开的同级分区；项目元素分角色/场景/道具，分镜有独立主标题，下面按原叙事顺序保留场景段落。多个对象可独立展开，素材缩略图不替换提交原图。
4. 提示词：编辑时预览压缩至140px，手机110px；正文最小220px，独立滚动，底部生成栏不随正文离开。保留常用参数，其他引擎参数放高级设置，不删除。
5. 大编辑器：通过原生 dialog 放大全文，仍编辑同一对象/类型的受控草稿；Escape/完成关闭，焦点返回。异步A结果不能写B，草稿切换会卸载旧弹窗。
6. 助手入口：明确文字“让助手修改”，保留原目标捕获、对象线程和旧 Agent 调用链。
7. 排版与动效：目录正文12px、分区标题13px、中栏标题14–15px、提示词14px；大编辑器15px，手机输入16px。不使用随视口缩放的字号，不靠负字距挤内容。展开和弹层约160ms淡入/轻位移，hover约130–160ms，遵守 reduced-motion。

8. 可调栏宽：目录默认320px、助手360px，两条8px分隔线支持拖动、方向键（10px）、Shift+方向键（40px）、双击复位。仅松手保存到本项目 `workspaceLayoutWidths`；缩窗只临时收窄，不覆盖偏好。目录220–480px、助手280–560px，中间至少420px；小于1200px沿用抽屉叠层。
9. 分区质感：8px工作区间隔、6px圆角、细边框；顶栏50px。毛玻璃仅顶栏、抽屉标题和浮层使用8px模糊，媒体与正文表面不做模糊；不支持的环境有实色回退。拖动不触发磁盘逐帧保存，卸载释放 pointer capture 与事件监听。
10. 左栏第二轮：默认去掉常驻勾选框和对象“更多”按钮。多选通过 Cmd/Ctrl 或 Shift 点击保留；分区13px/600、分组12px/500、条目12px、状态11px。描述默认三行，真实溢出才显示展开，全文不截断保存；剧本摘录同样处理。
11. 右键菜单：对象操作在鼠标位置打开，空白目录可新增素材；新增图片、新增视频、新增镜头仅创建草稿对象，不提交生成。新增镜头追加空白数据，不重编号旧镜头、不复制对白/关系/参考/付费产物。菜单支持键盘、Esc、点击外部关闭；只有点“从项目删除”后再打开影响范围确认。

## 助手对话设计

助手对话栏的设计取舍：普通短段落穿插执行阶段卡；收起时以状态、产物缩略图为主，展开后是竖向步骤线、完成标志和必要记录。右侧标题为“对话”，不逐条重复大头像与作者名。

设计取舍：顶部使用“对话”，回复去掉星形标记加“鲲鹏”的作者行；普通解释保持文本，真实工具阶段和产物使用可展开工作记录。阶段失败/待确认不装成完成，Skill 只从真实调用轨迹展示。保留对象范围、Harness、确认、消息队列、快照与字段回退，不用新 UI 替换执行器。具体落地以《助手对话设计精修》及实施报告为准。

原生构建结果见同目录《工作台重构实施报告》的本轮增量。本文不会在验证完成前声称全量工作台重构已经完成。

# 对话设计与功能二次对照

参考：Safari 中实际打开的 Flova 项目。检查消息末尾、执行阶段、提示词展开、模型菜单和历史入口；没有提交生成或修改参考项目。

| 维度 | Flova 实际表现 | 鲲鹏问题与本次处理 |
| --- | --- | --- |
| 消息层级 | 用户参考素材和要求聚合；助手正文开放排版 | 延续共享字号、留白和中性色；侧栏历史消息补上真实 filePaths 附件，避免发送后看不出参考了哪张图 |
| 过程可见性 | 折叠记录保留状态，展开显示阶段和提示词 | 折叠摘要增加真实当前动作、多步骤进行状态、完成/失败/跳过数量；不伪造进度百分比 |
| 结果顺序 | 媒体结果先于总结正文 | 工坊回复改为紧凑过程 → 返回媒体 → 解释正文；保留已有 Inspector 预览入口 |
| 附件一致性 | 输入素材有缩略图与名称 | 主对话和侧栏复用同一附件组件；图片显示缩略图，其他文件保留类型图标；历史附件没有删除草稿的按钮 |
| 完成语义 | 失败阶段明确区分 | 只有工具回执的主对话也显示执行记录；不再把生成/导出统称为编辑；没有成功回执的不标为成功 |
| 提示词 | 可展开查看完整生成提示词 | 鲲鹏保留已有操作详情、提示词修订回执和字段改动；修订回执不等同于完整历史提示词，因此没有声称这一点完全对齐 |
| 模型选择 | 图片、视频、音乐、音频分类在生成模型菜单中 | 鲲鹏助手模型选择负责推理模型，生成模型有自己的入口，两者语义不同；保留原选择范围，未把两种模型混成一个开关 |
| 输入与阅读 | 固定输入区、可调整高度、上下跳转 | 保留鲲鹏自动增高、原快捷键与滚动行为；补上中文输入法组合态保护，避免选词触发发送或引用选择 |
| 历史操作 | 历史对话入口、恢复操作 | 保留已有会话切换、项目快照、字段回退；本次没有触发真实项目恢复 |

## 范围

没有新增功能按钮，没有引入首尾帧、声音剪辑、能力合同或审片交付模块。没有移植 Flova 的拖动调节输入高度、额外上下跳转按钮或生成模型总菜单。视觉与展示层已改进，不代表两套产品所有能力已等同。

## 验证

使用真实 React 组件的隔离预览检查深色窄栏、浅色文案栏、附件与折叠记录。预览使用示例数据，不是已安装客户端。自动检查覆盖返回结果顺序、失败与等待语义、原有模型/确认入口、历史附件和媒体去重；没有调用付费生成工具。

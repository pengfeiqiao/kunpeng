# 视频深度转换工作流

原流程在本地记忆和隔离技能中，没有随产品分发的可执行入口。原上游读取按帧序号stride取样，对VFR输入可能改变播放时长；历史环境说明还混有单帧V2模型与时序Video模型。

本次新增同名正式 library 技能 video-depth-estimation-pipeline、可执行转换脚本和环境说明，并在全局Agent提示中明确路由。Tauri现有资源配置会打包该技能；不新增前台按钮、不改loop/harness、也不调用生成/付费API。

流程：输入/环境检查 → FFmpeg按时间戳转恒定帧率 → 官方Video Depth Anything Small时序推理 → 全片统一灰度范围 → 原显示尺寸MP4与可选原声 → 时长/帧数/音轨核验 → 原子发布与JSON回执。

默认15fps、256网络输入、工作长边720、FP32。输出放大到原尺寸不意味着恢复了原生高分辨率深度细节。离线缓存预算保护；不存在的环境明确报错并给出配置方法，不自动改代理、换镜像或改用边缘图。重复输出拒绝覆盖，锁保护并发，失败不发布半成品。

测试：Python真实FFmpeg回归覆盖VFR时间轴、有声、音频长于视频、防覆盖和模型失败清理（模型本身用桩，非准确率测试）；Agent/技能回归22项通过。真实输入另行执行模型转换并抽帧核验。

真实转换完成：输入视频流28.516667秒，产物428帧/15fps/1280×720，视频28.533008秒，保留AAC原声。抽帧确认近亮远暗与人物/环境层次；整段解码通过。另交付全片99.5百分位灰度优化版。3项Python测试与22项Agent/技能测试通过。本机正式技能与三条旧流程记忆已同步更新，并保留备份。

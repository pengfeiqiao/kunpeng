# 连续对话、空行与生成确认反馈修复

## 已验证原因与修改

1. 声音助手的草稿长期保留首次选择对象时的内容快照。第一轮修改音色或配音提示词后，后续新消息仍比较旧修订，因此被标记为“未发送”。新消息现在保留对象身份并捕获当前内容；排队后的修订检查继续有效。原有重试、编辑重发及再次发送同一句话可恢复确定未发送的失败项，已提交或状态不明的任务不得重放。
2. `isGenerationToolName` 把包含 `generation` 的工具都视为媒体生成，误将 `project_update_generation_prompt` 和 `project_get_generation_draft` 放入生成确认流程。分类已修正。手动确认模式中，修改提示词仍可能出现普通编辑确认，但标题是“修改提示词”，明确说明不会生成媒体，不显示生成费用或模型表单。
3. 普通 coordinator 和 DSH 工具通道现在都在确认前检查本轮范围。明确只改提示词或禁止生成时，实际生成工具被拒绝；读取及修改草稿继续可用。规则使用本轮用户请求，项目上下文不会被当成生成许可。
4. 用户消息在移除旧显示前缀后再次清理首尾空白；不改变发送内容和正文内部换行。
5. 产物目录入口优先使用实际回执中的文件目录，并检查目录是否存在。没有返回产物时说明目录尚未创建，不再把它笼统显示为无法打开。正在运行的提交显示等待结果，与历史状态不明的记录区分。

## 边界

截图中的“提交状态未确认”不能证明供应商生成失败或未收费。本次保留原记录，不自动重新生成；具体远端提交结果需要对应任务回执确认。附带原因总结中的网络、缓存等推测没有被当成已证实结论。本次更新源码，尚未替换安装版。

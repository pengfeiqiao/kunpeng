# 锚定图 SOP 与工具体感改进

产品取舍：沿用参考图、候选版本、采纳与项目文案，不增设页面或按钮。对话、工坊、画布共享简短内部规则，完整 anchor-frame-production 技能按需调用。车型、驾驶位、时长等案例值改为项目事实；不引入首尾帧工作流。

## 已实现
- 新附件保存来源路径，恢复历史时重读最近八张图片；丢失图片明确报告未看到像素。旧版本仅剩占位文字的消息无法凭空恢复图片。
- 原生识图提示要求证据、反证、区域、主观置信理由；看不清不能判定通过。
- image_inspect：原图裁切、同尺寸像素差分、区域外变化统计与热图；后台 Worker 计算，不修改原图。最多1600万像素；不做自动配准。
- 生图输出参考顺序回执，超量/无效参考显式拒绝，不静默截断。
- 批任务输出逐项状态与回执；同一运行重复调用被阻止时返回已有回执。运行中尚无结果的任务仍只能报告正在执行，不虚构成功或失败。
- task_status 区分远端提交ID与仅本地记录，保留未知状态下不自动重试。
- copywriting_get_state 支持 block_ids/query 读取完整匹配块及hash。
- 磁盘技能同轮重复调用返回摘要，force_full 可重读。
- 技能附带版本核验记录模板，写入已有项目文案；没有新增独立锚定图数据库或自动定版逻辑。

## 验证
完整 harness 935 项通过；附件恢复、差分、批任务与去重回执专项15项通过。最终 TypeScript 检查与生产构建通过，另有工具发现/文案回归6项通过。未调用付费生成服务，视觉语义准确率未作实际模型评测。
